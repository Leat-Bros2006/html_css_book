HTML5 & CSS3 01. Introduction to Web Development

01. Introduction to Web Development

1. Definition (តើវាជាអ្វី?):

Web Development គឺជាដំណើរការបង្កើតគេហទំព័រដែលដំណើរការតាមគំរូ Client-Server។ ផ្នែកដែលអ្នកប្រើប្រាស់មើលឃើញលើ Browser ហៅថា Frontend (ប្រើ HTML5 សម្រាប់បង្កើតគ្រោងឆ្អឹង និង CSS3 សម្រាប់រចនារូបរាង) ចំណែកផ្នែកគ្រប់គ្រង Database នៅលើ Server ហៅថា Backend។

2. Purpose (ហេតុអ្វីត្រូវប្រើ HTML5?):

  • កំណត់រចនាសម្ព័ន្ធមាតិកាគេហទំព័រ ដូចជាចំណងជើង កថាខណ្ឌ រូបភាព តារាង និងប៊ូតុង។
  • ផ្តល់ព័ត៌មានតាមរយៈ HTML Elements, Tags និង Attributes ឱ្យ Browser បកប្រែបង្ហាញលើអេក្រង់។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់នៅរាល់ពេលចាប់ផ្តើមបង្កើតគេហទំព័រ ឬកម្មវិធី Web Application គ្រប់ប្រភេទ។

4. Syntax (ឧទាហរណ៍ទម្រង់ HTML5 Element និង Attributes):

<!-- Opening Tag + Attributes + Content + Closing Tag -->
<h1 id="main-title" class="hero-heading">សូមស្វាគមន៍មកកាន់ HTML5!</h1>
<p title="សេចក្តីពន្យល់">ការរៀន Web Development ចាប់ផ្តើមពីការយល់ដឹងអំពី HTML និង CSS។</p>

5. Explanation (ការពន្យល់កូដ):

  • <h1>...</h1> គឺជា HTML Element សម្រាប់បង្កើតចំណងជើងធំបំផុតនៅលើទំព័រ។
  • id="main-title" និង class="hero-heading" គឺជា Attributes សម្រាប់កំណត់ឈ្មោះសម្គាល់ឱ្យ Element។
  • title="សេចក្តីពន្យល់" បង្ហាញប្រអប់អត្ថបទតូចមួយ (Tooltip) នៅពេលដាក់ Mouse ពីលើកថាខណ្ឌ។

6. Output (លទ្ធផល):

បង្ហាញចំណងជើងធំ "សូមស្វាគមន៍មកកាន់ HTML5!" និងអត្ថបទកថាខណ្ឌមួយជួរនៅលើផ្ទាំង Web Browser។

7. Practice (លំហាត់អនុវត្ត):

ចូរសរសេរកូដបង្កើតចំណងជើង <h2> ដែលមាន Attribute class="course-name" និងកថាខណ្ឌ <p> ណែនាំខ្លួនអ្នក 1 ប្រយោគ។

HTML5 & CSS3 02. HTML Document Structure

02. HTML Document Structure (គ្រោងឆ្អឹងទំព័រស្តង់ដារ)

1. Definition (តើវាជាអ្វី?):

HTML Document Structure (ឬហៅថា HTML5 Boilerplate) គឺជាគ្រោងឆ្អឹងកូដគោលដែលគ្រប់ឯកសារ .html ទាំងអស់ត្រូវតែមាន រួមបញ្ចូលទាំង <!DOCTYPE html>, <html>, <head>, <meta>, <title> និង <body>។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ប្រាប់ Browser ឱ្យដំណើរការក្នុងទម្រង់ HTML5 Standards Mode តាមរយៈ <!DOCTYPE html>។
  • កំណត់ការបង្ហាញអក្សរខ្មែរមិនឱ្យខូចទ្រង់ទ្រាយតាមរយៈ <meta charset="UTF-8">។
  • ធ្វើឱ្យគេហទំព័រគាំទ្រការបង្ហាញលើអេក្រង់ទូរស័ព្ទដៃតាមរយៈ <meta name="viewport" ...>។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅរាល់ពេលចាប់ផ្តើមបង្កើតឯកសារ HTML ថ្មីគ្រប់ទំព័រ (ក្នុង VS Code អាចវាយសញ្ញា ! រួចចុច Tab)។

4. Syntax (ទម្រង់កូដ HTML5 Boilerplate ពេញលេញ):

<!DOCTYPE html>
<html lang="km">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>គេហទំព័រដំបូងរបស់ខ្ញុំ</title>
</head>
<body>
  <!-- មាតិកាដែលបង្ហាញលើអេក្រង់ Browser -->
  <h1>សួស្តីពិភពលោក!</h1>
</body>
</html>

5. Explanation (ការពន្យល់កូដ):

  • <html lang="km"> គឺជា Root Element ដែលរុំព័ទ្ធកូដទាំងអស់ និងបញ្ជាក់ថាទំព័រនេះប្រើភាសាខ្មែរ។
  • <head> ផ្ទុកព័ត៌មាន Metadata និង <title> សម្រាប់បង្ហាញឈ្មោះនៅលើរបារ Browser Tab។
  • <body> ផ្ទុករាល់មាតិកាទាំងអស់ដែលអ្នកប្រើប្រាស់មើលឃើញផ្ទាល់នៅលើទំព័រ។

6. Output (លទ្ធផល):

បង្ហាញឈ្មោះ "គេហទំព័រដំបូងរបស់ខ្ញុំ" នៅលើ Browser Tab និងបង្ហាញអក្សរធំ "សួស្តីពិភពលោក!" នៅក្នុងទំព័រ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតឯកសារ about.html ដោយសរសេរ HTML5 Boilerplate ពេញលេញ និងដាក់ Comment បញ្ជាក់ឈ្មោះអ្នកនិពន្ធ។

HTML5 & CSS3 03. HTML Text Elements

03. HTML Text Elements & Entities

1. Definition (តើវាជាអ្វី?):

HTML Text Elements គឺជាបណ្តុំស្លាកកូដសម្រាប់រៀបចំអត្ថបទ រួមមានចំណងជើង (<h1> ដល់ <h6>), កថាខណ្ឌ (<p>), ការចុះបន្ទាត់ (<br>), បន្ទាត់ផ្តេក (<hr>), អក្សរដិត/ទ្រេត (<strong>, <em>), សន្ទស្សន៍/ស្វ័យគុណ (<sub>, <sup>) និង HTML Entities។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្កើតឋានានុក្រមអត្ថបទ (Visual Hierarchy) ឱ្យអ្នកអាន និង Google Search យល់ពីចំណងជើងមេ និងចំណងជើងរង។
  • សង្កត់ន័យសំខាន់លើពាក្យគន្លឹះតាមរយៈ Semantic Tags (<strong> និង <em>)។
  • បង្ហាញនិមិត្តសញ្ញាពិសេសដូចជា &copy; (©), &lt; (<) និង &gt; (>)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលសរសេរអត្ថបទមេរៀន អត្ថបទព័ត៌មាន រូបមន្តគណិតវិទ្យា/គីមីវិទ្យា និងសេចក្តីជូនដំណឹងលើវេបសាយ។

4. Syntax (ឧទាហរណ៍ការរៀបចំអត្ថបទ និងនិមិត្តសញ្ញា):

<h1>មេរៀនវិទ្យាសាស្ត្រ និងគណិតវិទ្យា</h1>
<p>ទឹកមានរូបមន្តគីមី H<sub>2</sub>O និងសមីការថាមពល E = mc<sup>2</sup>។</p>
<p><strong>ចំណាំសំខាន់៖</strong> សូមអានមេរៀនដោយ <em>យកចិត្តទុកដាក់</em>។</p>
<hr>
<p>&copy; 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង &bull; ស្លាកកូដ៖ &lt;strong&gt;</p>

5. Explanation (ការពន្យល់កូដ):

  • <sub>2</sub> ទម្លាក់លេខ 2 ទៅផ្នែកខាងក្រោម (H₂O) រីឯ <sup>2</sup> លើកលេខ 2 ជាស្វ័យគុណ (mc²)។
  • <strong> ធ្វើឱ្យអក្សរដិត និងប្រាប់ Screen Reader ថាជាពាក្យសំខាន់។
  • <hr> គូសបន្ទាត់ផ្តេកខណ្ឌចែកផ្នែកអត្ថបទ។

6. Output (លទ្ធផល):

បង្ហាញចំណងជើងធំ រូបមន្ត H₂O និង E = mc² អក្សរដិត/ទ្រេត បន្ទាត់ខណ្ឌចែក និងសញ្ញា © 2026។

7. Practice (លំហាត់អនុវត្ត):

ចូរសរសេរកូដបង្ហាញអត្ថបទដែលមានចំណងជើង <h1>, <h2> រូបមន្ត CO₂ និងនិមិត្តសញ្ញាពាណិជ្ជសញ្ញា &reg;។

HTML5 & CSS3 04. Links and Navigation

04. Links and Navigation (តំណភ្ជាប់ និងម៉ឺនុយ)

1. Definition (តើវាជាអ្វី?):

ស្លាក <a> (Anchor Element) ត្រូវបានប្រើសម្រាប់បង្កើតតំណភ្ជាប់ (Hyperlinks) ដើម្បីផ្លាស់ទីពីទំព័រមួយទៅទំព័រមួយទៀត លោតទៅផ្នែកណាមួយក្នុងទំព័រដដែល ផ្ញើអ៊ីមែល ឬហៅទូរស័ព្ទ។

2. Purpose (ប្រភេទតំណភ្ជាប់សំខាន់ៗ):

  • Internal Links: ភ្ជាប់ទៅកាន់ឯកសារក្នុងវេបសាយតែមួយ (ឧ. href="about.html" ឬ href="#contact")។
  • External Links: ភ្ជាប់ទៅកាន់វេបសាយខាងក្រៅ (ប្រើ target="_blank" ដើម្បីបើកក្នុង Tab ថ្មី)។
  • Email & Tel Links: ប្រើ mailto: សម្រាប់បើកកម្មវិធីផ្ញើអ៊ីមែល និង tel: សម្រាប់ហៅទូរស័ព្ទ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលបង្កើតរបារម៉ឺនុយ (<nav>), ប៊ូតុងអានបន្ត, មាតិកាសៀវភៅ និងផ្នែកទំនាក់ទំនង។

4. Syntax (ឧទាហរណ៍ការបង្កើត Navigation Menu):

<nav>
  <a href="index.html">ទំព័រដើម</a> |
  <a href="#courses">វគ្គសិក្សា</a> |
  <a href="https://developer.mozilla.org" target="_blank" rel="noopener">ឯកសារ MDN</a> |
  <a href="mailto:info@brosliketeaching.com">ផ្ញើអ៊ីមែល</a> |
  <a href="tel:+855979445608">ហៅទូរស័ព្ទ</a>
</nav>

បង្ហាញស៊ុមទម្រង់ចុះឈ្មោះដែលមានប្រអប់វាយអ៊ីមែល ប្រអប់ជ្រើសរើសវគ្គសិក្សា និងប៊ូតុង Submit។

09. Semantic HTML5 Elements

1. Definition (តើវាជាអ្វី?):

Semantic HTML5 គឺជាការប្រើប្រាស់ស្លាកកូដដែលមានអត្ថន័យបញ្ជាក់ពីតួនាទីនៃផ្នែកនីមួយៗរបស់គេហទំព័រយ៉ាងច្បាស់លាស់ រួមមាន <header>, <nav>, <main>, <section>, <article>, <aside> និង <footer>។

2. Purpose (ភាពខុសគ្នារវាង Semantic និង Non-Semantic):

  • Semantic Elements: ប្រាប់ទាំងអ្នកសរសេរកូដ និង Browser ឱ្យដឹងពីអត្ថន័យមាតិកា (ឧ. <nav> គឺជារបារម៉ឺនុយ)។
  • Non-Semantic Elements (<div>, <span>): ប្រើសម្រាប់តែរុំព័ទ្ធដាក់ Style ដោយគ្មានអត្ថន័យពិសេសឡើយ។
  • ជួយបង្កើនពិន្ទុ SEO លើ Google Search និងជំនួយដល់កម្មវិធី Screen Readers សម្រាប់ជនពិការភ្នែក។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រៀបចំគ្រោងឆ្អឹងធំៗនៃគ្រប់ទំព័រវេបសាយទាំងអស់ ជំនួសឱ្យការប្រើ <div> គ្រប់កន្លែង។

4. Syntax (ឧទាហរណ៍គ្រោងឆ្អឹងគេហទំព័រតាមស្តង់ដារ Semantic HTML5):

<header>
  <nav>របារម៉ឺនុយគោល (Main Navigation)</nav>
</header>

<main>
  <section>
    <article><h2>អត្ថបទមេរៀនឯករាជ្យ (Blog Post)</h2></article>
  </section>
  <aside>របារព័ត៌មានចំហៀង (Sidebar)</aside>
</main>

<footer>&copy; 2026 រៀបចំដោយ៖ លាត ប្រុស</footer>

5. Explanation (ការពន្យល់កូដ):

  • <main> ផ្ទុកមាតិកាចម្បងរបស់ទំព័រ (ក្នុង 1 ទំព័រត្រូវមាន <main> តែមួយគត់)។
  • <article> សម្រាប់អត្ថបទពេញលេញឯករាជ្យ រីឯ <section> សម្រាប់បែងចែកផ្នែកនៃទំព័រ។

6. Output (លទ្ធផល):

បង្កើតបានរចនាសម្ព័ន្ធទំព័រមានក្បាល តួមាតិកា របារចំហៀង និងបាតទំព័រយ៉ាងត្រឹមត្រូវតាមស្តង់ដារ W3C។

7. Practice (លំហាត់អនុវត្ត):

ចូរកែប្រែកូដទំព័រព័ត៌មានដែលប្រើសុទ្ធតែ <div> ឱ្យមកប្រើប្រាស់ Semantic Tags ទាំង 7 ខាងលើ។

10. HTML Advanced Features, Accessibility & SEO

1. Definition (តើវាជាអ្វី?):

មុខងារកម្រិតខ្ពស់របស់ HTML5 រួមមានប្រអប់បិទ/បើកស្វ័យប្រវត្តិ (<details>, <summary>), របារភាគរយ (<progress>), រង្វាស់កម្រិត (<meter>), Custom Data Attributes (data-*) និងគោលការណ៍ Accessibility (ARIA) / SEO។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្កើតប្រអប់សំណួរ-ចម្លើយ (FAQ Accordion) ដោយប្រើ <details> មិនបាច់សរសេរ JavaScript។
  • រក្សាទុកទិន្នន័យបន្ថែមនៅលើស្លាក HTML តាមរយៈ data-id ឬ data-category។
  • ប្រើប្រាស់ Global Attributes ដូចជា title, hidden, tabindex និង aria-label។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលបង្កើតផ្នែក FAQ, របារបង្ហាញកម្រិតជំនាញ (Skill Bars) និងការធ្វើឱ្យវេបសាយជាប់ចំណាត់ថ្នាក់ល្អលើ Google។

4. Syntax (ឧទាហរណ៍ Details/Summary, Progress និង Meter):

<details data-faq="seo-guide">
  <summary>តើធ្វើដូចម្តេចដើម្បីឱ្យ HTML គាំទ្រ SEO បានល្អ?</summary>
  <p>ត្រូវប្រើប្រាស់ Semantic Tags, ដាក់ meta description និងដាក់ alt គ្រប់រូបភាព។</p>
</details>

<p>កម្រិតសិក្សា៖ <progress value="85" max="100">85%</progress></p>
<p>ទំហំផ្ទុកទិន្នន័យ៖ <meter value="0.75">75%</meter></p>

5. Explanation (ការពន្យល់កូដ):

  • <summary> គឺជាចំណងជើងដែលអ្នកប្រើប្រាស់អាចចុចដើម្បីបើក ឬបិទមាតិកាក្នុង <details>។
  • <progress value="85" max="100"> បង្ហាញរបារវឌ្ឍនភាពបាន 85%។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់សំណួរដែលអាចចុចបើកមើលចម្លើយបាន ព្រមទាំងរបារ Progress និង Meter ចំនួន 2។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតផ្នែកសំណួរឧស្សាហ៍ជួប (FAQ) ចំនួន 3 សំណួរដោយប្រើប្រាស់ <details> និង <summary>។

11. Introduction to CSS3 (ការរចនាគេហទំព័រ)

1. Definition (តើវាជាអ្វី?):

CSS3 (Cascading Style Sheets) គឺជាភាសាសម្រាប់តុបតែងរូបរាង ពណ៌ ពុម្ពអក្សរ និងរៀបចំប្លង់ (Layout) ឱ្យធាតុ HTML។ ការសរសេរ CSS មាន 3 របៀបគឺ៖ Inline CSS, Internal CSS និង External CSS។

2. Purpose (ហេតុអ្វីត្រូវប្រើ External CSS?):

  • បំបែកកូដរចនា (style.css) ចេញពីកូដរចនាសម្ព័ន្ធ (index.html) ធ្វើឱ្យកូដស្អាត និងងាយកែប្រែ។
  • ឯកសារ CSS តែមួយអាចភ្ជាប់ទៅកាន់ទំព័រ HTML រាប់រយទំព័រតាមរយៈស្លាក <link rel="stylesheet">។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ External CSS ជាស្តង់ដារនៅក្នុងគ្រប់ Project អភិវឌ្ឍន៍គេហទំព័រទាំងអស់។

4. Syntax (ទម្រង់ក្បួន CSS Rule និងការភ្ជាប់ឯកសារ):

<!-- 1. ភ្ជាប់ក្នុងផ្នែក <head> នៃឯកសារ index.html -->
<link rel="stylesheet" href="css/style.css">

/* 2. សរសេរក្នុងឯកសារ css/style.css: Selector { property: value; } */
.welcome-card {
  background-color: #E0F2FE;
  color: #0284C7;
  padding: 16px;
}

5. Explanation (ការពន្យល់កូដ):

  • .welcome-card គឺជា Selector សម្រាប់ចាប់យកធាតុ HTML ដែលមាន class="welcome-card"។
  • background-color: #E0F2FE; គឺជា Declaration ដែលមាន Property និង Value បញ្ចប់ដោយសញ្ញា ;។

6. Output (លទ្ធផល):

ប្រអប់ HTML ដែលមាន Class welcome-card នឹងបង្ហាញផ្ទៃពណ៌ខៀវខ្ចី និងអក្សរពណ៌ខៀវដិត។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតឯកសារ style.css រួចភ្ជាប់ទៅកាន់ index.html ដើម្បីកំណត់ពណ៌ផ្ទៃខាងក្រោយឱ្យ body និងពណ៌អក្សរឱ្យ h1។

12. CSS Selectors, Pseudo-Classes & Pseudo-Elements

1. Definition (តើវាជាអ្វី?):

CSS Selectors គឺជាទម្រង់សម្រាប់ជ្រើសរើសធាតុ HTML មកដាក់ Style រួមមាន៖ Element (p), Class (.card), ID (#header), Universal (*), Combinators (div p, ul > li), Attribute ([type="email"]), Pseudo-Classes (:hover) និង Pseudo-Elements (::before, ::after)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ចាប់យកធាតុ HTML បានយ៉ាងជាក់លាក់ដោយមិនបាច់បង្កើតឈ្មោះ Class ច្រើនហួសហេតុ។
  • បង្កើតអន្តរកម្មពេលដាក់ Mouse ពីលើ (:hover) ឬពេលចុចក្នុងប្រអប់ Input (:focus)។
  • បន្ថែមនិមិត្តសញ្ញា ឬបន្ទាត់តុបតែងពីមុខ/ពីក្រោយអត្ថបទតាមរយៈ ::before និង ::after។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ Class Selector (.name) ជាគោលសម្រាប់គ្រប់ Components និងប្រើ Pseudo-classes សម្រាប់ប៊ូតុង/តំណភ្ជាប់។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ Selectors និង Pseudo-Classes):

.btn-primary {
  background-color: #0284C7;
  color: #FFFFFF;
}
.btn-primary:hover {
  background-color: #0369A1;
}
.chapter-heading::before {
  content: "★ ";
  color: #F59E0B;
}

5. Explanation (ការពន្យល់កូដ):

  • .btn-primary:hover ប្តូរពណ៌ប៊ូតុងទៅជាខៀវដិតនៅពេលអ្នកប្រើប្រាស់ដាក់ Mouse ពីលើ។
  • ::before បង្កើតសញ្ញាផ្កាយពណ៌ទឹកក្រូចនៅពីមុខចំណងជើងដោយស្វ័យប្រវត្តិតាមរយៈ content: "★ "។

6. Output (លទ្ធផល):

បង្ហាញប៊ូតុងដែលប្តូរពណ៌ពេល Hover និងចំណងជើងដែលមានសញ្ញាផ្កាយពណ៌ទឹកក្រូចនៅខាងមុខ។

7. Practice (លំហាត់អនុវត្ត):

ចូរប្រើប្រាស់ tr:nth-child(even) ដើម្បីដាក់ពណ៌ផ្ទៃខាងក្រោយឆ្លាស់គ្នាឱ្យជួរដេកនៃតារាង HTML។

13. CSS Colors, Backgrounds & Gradients

1. Definition (តើវាជាអ្វី?):

CSS Colors និង Backgrounds គឺជាការកំណត់ប្រព័ន្ធពណ៌ (HEX, RGB/RGBA, HSL), រូបភាពផ្ទៃខាងក្រោយ (background-image, background-size, background-position) និងការច្របល់ពណ៌ (linear-gradient, radial-gradient)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្កើតប្រព័ន្ធពណ៌ (Color Palette) ឱ្យស៊ីគ្នាពេញមួយគេហទំព័រ និងមានកម្រិតភាពច្បាស់ (Contrast) ងាយស្រួលអាន។
  • ប្រើប្រាស់ rgba() សម្រាប់បង្កើតពណ៌ថ្លា (Transparency/Opacity) ដូចជាផ្ទៃស្រមោល ឬផ្ទាំង Overlay។
  • បង្កើតផ្ទៃ Hero Banner ដ៏ទាក់ទាញដោយប្រើរូបភាព ឬការច្របល់ពណ៌ Gradient។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលកំណត់ពណ៌អក្សរ ពណ៌ប៊ូតុង ផ្ទៃកាត និងផ្ទាំង Banner ធំៗរបស់គេហទំព័រ។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ Background Image និង Linear Gradient):

.hero-banner {
  background-image: linear-gradient(135deg, #0284C7 0%, #0F172A 100%);
  color: #FFFFFF;
}

.photo-cover {
  background-image: url('../assets/images/banner.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

5. Explanation (ការពន្យល់កូដ):

  • linear-gradient(135deg, ...) ច្របល់ពណ៌បញ្ឆិត 135 ដឺក្រេពីពណ៌ខៀវទៅពណ៌ទឹកប៊ិចចាស់។
  • background-size: cover ពង្រីករូបភាពឱ្យពេញប្រអប់ស្អាតដោយមិនឱ្យរូបភាពទាញខូចទ្រង់ទ្រាយ។

6. Output (លទ្ធផល):

14. CSS Typography & Google Fonts

1. Definition (តើវាជាអ្វី?):

CSS Typography គឺជាការកំណត់រចនាប័ទ្មអក្សរ រួមមានប្រភេទពុម្ពអក្សរ (font-family), ទំហំ (font-size), កម្រាស់ (font-weight), ការតម្រឹម (text-align), គម្លាតបន្ទាត់ (line-height), គម្លាតតួអក្សរ (letter-spacing) និងការភ្ជាប់ពុម្ពអក្សរពី Google Fonts។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលកំណត់ Global Typography លើស្លាក body និងការរៀបចំចំណងជើងមេរៀន។

body {
  font-family: 'Kantumruy Pro', sans-serif;
  font-size: 16px;
  line-height: 1.75;
}
.section-title {
  font-weight: 700;

  letter-spacing: 0.05em;
}

5. Explanation (ការពន្យល់កូដ):

  • @import url(...) ទាញយកពុម្ពអក្សរ Kantumruy Pro ពីម៉ាស៊ីនមេរបស់ Google Fonts។
  • text-transform: uppercase បម្លែងអក្សរអង់គ្លេសឱ្យទៅជាអក្សរធំទាំងអស់ដោយស្វ័យប្រវត្តិ។

អត្ថបទទាំងអស់នៅក្នុងទំព័រនឹងបង្ហាញដោយប្រើពុម្ពអក្សរ Kantumruy Pro យ៉ាងច្បាស់ និងមានគម្លាតបន្ទាត់ស្រឡះល្អ។

15. CSS Box Model (គំរូប្រអប់នៃធាតុ HTML)

1. Definition (តើវាជាអ្វី?):

CSS Box Model គឺជាគោលការណ៍ដែលចាត់ទុកគ្រប់ធាតុ HTML ទាំងអស់ជាប្រអប់ចតុកោណ ដែលផ្សំឡើងពី 4 ស្រទាប់៖ Content (មាតិកា), Padding (គម្លាតខាងក្នុងស៊ុម), Border (បន្ទាត់ស៊ុម) និង Margin (គម្លាតខាងក្រៅស៊ុម)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ box-sizing: border-box?):

  • តាមលំនាំដើម (content-box) ការបន្ថែម padding នឹងធ្វើឱ្យប្រអប់រីកទំហំធំជាង width ដែលបានកំណត់។
  • ការប្រើ box-sizing: border-box បញ្ចូលទាំង Padding និង Border ឱ្យស្ថិតនៅក្នុងទទឹង width តែមួយ មិនឱ្យខូចប្លង់។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់កំណត់ទំហំ គម្លាត ស៊ុមមូល (border-radius) និងស្រមោល (box-shadow) របស់គ្រប់ប្រអប់ Card និងប៊ូតុង។

4. Syntax (ឧទាហរណ៍ការកំណត់ Box Model លើប្រអប់ Card):

*, *::before, *::after {
  box-sizing: border-box;
}

.profile-card {
  width: 320px;
  padding: 24px;
  margin: 16px auto;
  border: 1px solid #E2E8F0;
  border-radius: 12px;
  box-shadow: 0 4px 16px rgba(15, 23, 42, 0.08);
}

5. Explanation (ការពន្យល់កូដ):

  • padding: 24px បង្កើតគម្លាតទំនេរ 24px នៅខាងក្នុងស៊ុមជុំវិញអត្ថបទ។
  • margin: 16px auto ដាក់គម្លាតលើ-ក្រោម 16px និងរុញប្រអប់ឱ្យស្ថិតនៅចំកណ្តាលទំព័រ (auto)។
  • border-radius: 12px និង box-shadow ធ្វើឱ្យជ្រុងប្រអប់មូលស្អាត និងមានស្រមោលផុសឡើង។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់ Card ទទឹង 320px គត់ ស្ថិតនៅចំកណ្តាលអេក្រង់ មានជ្រុងមូល និងស្រមោលទំនើប។

7. Practice (លំហាត់ទី ៤):

ចូររចនាប្រអប់ Course Card ចំនួន 2 ដែលមានប្រើប្រាស់ padding, border, border-radius និង box-shadow។

16. CSS Display and Position (ការកំណត់ទីតាំងធាតុ)

1. Definition (តើវាជាអ្វី?):

Property display កំណត់របៀបដែលប្រអប់បង្ហាញ (block, inline, inline-block, none) ចំណែក position កំណត់ទីតាំងរបស់ធាតុ (static, relative, absolute, fixed, sticky) រួមជាមួយការកំណត់ស្រទាប់លើ-ក្រោម (z-index)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ដាក់ស្លាកបញ្ចុះតម្លៃ (Badge) នៅជ្រុងលើស្តាំនៃរូបភាពផលិតផលដោយប្រើ relative (លើមេ) និង absolute (លើកូន)។
  • រក្សារបារម៉ឺនុយ Navbar ឱ្យនៅជាប់ផ្នែកខាងលើនៃអេក្រង់ពេលអូសចុះក្រោមដោយប្រើ position: sticky; top: 0;។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលធ្វើ Sticky Header, ប៊ូតុងអណ្តែតជ្រុងអេក្រង់ (fixed), ផ្ទាំង Modal និងការដាក់ធាតុត្រួតលើគ្នា។

4. Syntax (ឧទាហរណ៍ការប្រើ Relative និង Absolute រួមគ្នា):

.product-card {
  position: relative; /* កំណត់ប្រអប់មេជាគោល */
  width: 280px;
  padding: 20px;
}

.sale-badge {
  position: absolute; /* កំណត់ទីតាំងកូនធៀបនឹងប្រអប់មេ */
  top: 12px;
  right: 12px;
  z-index: 10;
}

5. Explanation (ការពន្យល់កូដ):

  • position: relative នៅលើ .product-card ឃាត់មិនឱ្យកូនដែលមាន absolute រត់ចេញក្រៅប្រអប់មេ។
  • top: 12px; right: 12px; ដាក់ស្លាក .sale-badge នៅជ្រុងខាងលើផ្នែកខាងស្តាំយ៉ាងជាក់លាក់។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់ផលិតផលដែលមានស្លាកបញ្ចុះតម្លៃស្ថិតនៅជ្រុងលើស្តាំនៃកាតនោះ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតរបារម៉ឺនុយដែលមាន position: sticky; top: 0; និងប៊ូតុង "Back to Top" ដែលមាន position: fixed។

17. CSS Flexbox Layout (ការរៀបប្លង់បត់បែន 1 វិមាត្រ)

1. Definition (តើវាជាអ្វី?):

CSS Flexbox (display: flex) គឺជាប្រព័ន្ធរៀបចំប្លង់ 1 វិមាត្រ (ជាជួរដេក row ឬជួរឈរ column) ដែលជួយសម្រួលដល់ការតម្រឹមធាតុកូន (Flex Items) និងការចែកចាយគម្លាតនៅក្នុងប្រអប់មេ (Flex Container)។

2. Purpose (Properties សំខាន់ៗរបស់ Flexbox):

  • justify-content តម្រឹមធាតុតាមអ័ក្សមេ (ដូចជា center, space-between, space-around)។
  • align-items តម្រឹមធាតុតាមអ័ក្សកាត់ (ដូចជាដាក់ឱ្យចំកណ្តាលជួរឈរ center)។
  • flex-wrap: wrap និង gap អនុញ្ញាតឱ្យធាតុកូនទម្លាក់ជួរពេលអេក្រង់តូច និងមានគម្លាតស្មើៗគ្នា។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រៀបចំរបារ Navigation Bar, ការដាក់ធាតុឱ្យចំកណ្តាលអេក្រង់ និងការរៀបប៊ូតុង ឬកាតក្នុងជួរតែមួយ។

4. Syntax (ឧទាហរណ៍ការរៀបចំរបារ Navbar ជាមួយ Flexbox):

  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 32px;
}

.nav-links {
  display: flex;
  gap: 24px;
  list-style: none;
}

5. Explanation (ការពន្យល់កូដ):

  • justify-content: space-between រុញ Logo ទៅខាងឆ្វេងបំផុត និងរុញបញ្ជីម៉ឺនុយទៅខាងស្តាំបំផុត។
  • align-items: center តម្រឹមឱ្យ Logo និងអក្សរម៉ឺនុយស្ថិតនៅចំកណ្តាលជួរដេកស្មើគ្នា។
  • gap: 24px បង្កើតគម្លាត 24px រវាងតំណភ្ជាប់ម៉ឺនុយនីមួយៗ។

6. Output (លទ្ធផល):

បង្ហាញរបារម៉ឺនុយគេហទំព័រដែលមាន Logo នៅខាងឆ្វេង និងម៉ឺនុយរត់ជួរដេកយ៉ាងស្អាតនៅខាងស្តាំ។

7. Practice (លំហាត់អនុវត្ត):

ចូរប្រើប្រាស់ Flexbox ដើម្បីរៀបចំប្រអប់ Pricing Cards ចំនួន 3 ឱ្យរត់ក្នុងជួរតែមួយ និងមានកម្ពស់ស្មើគ្នា។

  • អាចធ្វើ Responsive Grid ដោយមិនបាច់សរសេរ Media Queries តាមរយៈ repeat(auto-fit, minmax(...))។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រៀបចំគ្រោងឆ្អឹងទំព័រធំៗ ប្លង់ Dashboard និងបញ្ជីកាតផលិតផលច្រើនជួរ។

4. Syntax (ឧទាហរណ៍ការបង្កើត Auto-Responsive Grid):

.course-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

.featured-item {
  grid-column: span 2; /* លាតសន្ធឹងឆ្លងកាត់ 2 ជួរឈរ */
}

5. Explanation (ការពន្យល់កូដ):

  • repeat(auto-fit, minmax(250px, 1fr)) កំណត់ឱ្យកាតនីមួយៗមានទទឹងយ៉ាងតិច 250px ហើយរៀបចំនួនជួរឈរស្វ័យប្រវត្តិទៅតាមទំហំអេក្រង់។
  • grid-column: span 2 ពង្រីកប្រអប់ពិសេសឱ្យធំស្មើនឹង 2 ប្រអប់ធម្មតា។

6. Output (លទ្ធផល):

19. Responsive Web Design & Media Queries

1. Definition (តើវាជាអ្វី?):

Responsive Web Design (RWD) គឺជាវិធីសាស្ត្ររចនាគេហទំព័រឱ្យអាចបត់បែនទំហំ និងប្លង់បានយ៉ាងស្អាតនៅលើគ្រប់ឧបករណ៍ទាំងអស់ (Mobile, Tablet, Laptop, Desktop) ដោយប្រើប្រាស់ @media queries។

2. Purpose (គោលការណ៍ Mobile-First និង Breakpoints):

  • Mobile-First Approach: សរសេរកូដ CSS គោលសម្រាប់អេក្រង់ទូរស័ព្ទជាមុន រួចប្រើ @media (min-width: ...) សម្រាប់ពង្រីកប្លង់លើអេក្រង់ធំ។
  • Breakpoints ស្តង់ដារ៖ Tablet (768px), Laptop (1024px), និង Desktop (1280px)។
  • Responsive Images: កំណត់ max-width: 100%; height: auto; ដើម្បីកុំឱ្យរូបភាពលៀនចេញក្រៅអេក្រង់។

3. When to Use (តើប្រើនៅពេលណា?):

ត្រូវអនុវត្តនៅគ្រប់គេហទំព័រសម័យទំនើបទាំងអស់ ព្រោះអ្នកប្រើប្រាស់ភាគច្រើនបើកវេបសាយតាមទូរស័ព្ទដៃ។

4. Syntax (ឧទាហរណ៍ការសរសេរ Mobile-First Media Queries):

/* 1. ប្លង់គោលសម្រាប់ទូរស័ព្ទ (Mobile Default: 1 ជួរឈរ) */
.card-container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* 2. អេក្រង់ Tablet ឡើងទៅ (>= 768px: 2 ជួរឈរ) */
@media screen and (min-width: 768px) {
  .card-container { grid-template-columns: repeat(2, 1fr); }
}

/* 3. អេក្រង់ Desktop ឡើងទៅ (>= 1024px: 3 ជួរឈរ) */
@media screen and (min-width: 1024px) {
  .card-container { grid-template-columns: repeat(3, 1fr); }
}

5. Explanation (ការពន្យល់កូដ):

  • @media screen and (min-width: 768px) ដំណើរការតែនៅពេលទទឹងអេក្រង់ចាប់ពី 768px ឡើងទៅប៉ុណ្ណោះ។

6. Output (លទ្ធផល):

ប្រអប់កាតបង្ហាញ 1 ជួរឈរលើទូរស័ព្ទ, 2 ជួរឈរលើ iPad និង 3 ជួរឈរលើកុំព្យូទ័រ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតរបារម៉ឺនុយដែលបង្ហាញជាជួរឈរលើទូរស័ព្ទ និងប្តូរមកជាជួរដេកនៅលើអេក្រង់ចាប់ពី 768px ឡើងទៅ។

20. CSS Units & Math Functions (clamp, min, max, calc)

1. Definition (តើវាជាអ្វី?):

CSS Units គឺជាខ្នាតសម្រាប់វាស់ទំហំដែលចែកចេញជា Absolute Unit (px) និង Relative/Viewport Units (%, em, rem, vw, vh) រួមជាមួយអនុគមន៍គណិតវិទ្យាទំនើប clamp(), min(), max() និង calc()។

2. Purpose (ភាពខុសគ្នានៃខ្នាតនីមួយៗ):

  • rem យោងតាមទំហំអក្សររបស់ Root <html> (តាមលំនាំដើម 1rem = 16px) ល្អបំផុតសម្រាប់ font-size និង padding។
  • vw និង vh យោងតាមទទឹង និងកម្ពស់អេក្រង់ (100vh = ពេញកម្ពស់អេក្រង់គត់)។
  • clamp(min, preferred, max) កំណត់ទំហំអក្សរឱ្យរីករួមស្វ័យប្រវត្តិតាមអេក្រង់នៅចន្លោះតម្លៃតូចបំផុត និងធំបំផុត។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ rem សម្រាប់ទំហំអក្សរ, px សម្រាប់កម្រាស់ Border និង clamp() / min() សម្រាប់ Responsive Layout។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ clamp, min និង calc):

.container {
  width: min(100% - 2rem, 1140px);
  margin-inline: auto;
}

.hero-title {
  font-size: clamp(1.5rem, 3vw + 1rem, 3rem);
}

.full-screen {
  min-height: calc(100vh - 70px);
}

5. Explanation (ការពន្យល់កូដ):

  • min(100% - 2rem, 1140px) ជ្រើសរើសតម្លៃណាដែលតូចជាង ធ្វើឱ្យប្រអប់មានទទឹងអតិបរមា 1140px និងសល់គម្លាតសងខាង 1rem លើទូរស័ព្ទ។
  • calc(100vh - 70px) គណនាកម្ពស់ពេញអេក្រង់ដកកម្ពស់របស់ Navbar 70px ចេញ។

6. Output (លទ្ធផល):

ទទួលបានប្រអប់ Container និងចំណងជើងដែលបត់បែនទំហំយ៉ាងរលូនលើគ្រប់អេក្រង់។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Hero Banner ដែលមានកម្ពស់ 100vh និងចំណងជើងប្រើប្រាស់អនុគមន៍ clamp()។

21. CSS Transitions and Transforms

1. Definition (តើវាជាអ្វី?):

transition គឺជាការកំណត់រយៈពេលផ្លាស់ប្តូររវាងស្ថានភាព 2 ឱ្យមានភាពទន់ភ្លន់ រីឯ transform គឺជាការផ្លាស់ប្តូរទីតាំង (translate), ពង្រីក/បង្រួម (scale), បង្វិលមុំ (rotate) និងទាញផ្អៀង (skew)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យប៊ូតុង ឬប្រអប់ផលិតផលអណ្តែតឡើងលើបន្តិចយ៉ាងរលូននៅពេលអ្នកប្រើប្រាស់ដាក់ Mouse ពីលើ (:hover)។
  • ការប្រើ transform និង opacity ដំណើរការលើ GPU ធ្វើឱ្យចលនារលូនមិនទាក់អេក្រង់។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើលើប៊ូតុង កាតផលិតផល រូបភាពក្នុង Gallery និងតំណភ្ជាប់ម៉ឺនុយ។

4. Syntax (ឧទាហរណ៍ការធ្វើ Hover Effect លើកាតផលិតផល):

.course-card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.course-card:hover {
  transform: translateY(-6px) scale(1.02);
  box-shadow: 0 12px 24px rgba(15, 23, 42, 0.12);
}

5. Explanation (ការពន្យល់កូដ):

  • transition: transform 0.3s ease កំណត់ឱ្យចលនាផ្លាស់ប្តូរប្រើរយៈពេល 0.3 វិនាទី។
  • translateY(-6px) scale(1.02) រុញកាតឡើងលើ 6px និងពង្រីកទំហំ 2% នៅពេល Hover។

6. Output (លទ្ធផល):

នៅពេលដាក់ Mouse លើកាត វានឹងអណ្តែតឡើងលើបន្តិចយ៉ាងស្រស់ស្អាត ហើយត្រឡប់មកដើមវិញពេលដក Mouse ចេញ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតស៊ុមរូបភាព (overflow: hidden) ដែលរូបភាពខាងក្នុងពង្រីក scale(1.1) នៅពេលដាក់ Mouse ពីលើ។

  • CSS Variables (--primary): កំណត់ពណ៌គោលនៅក្នុង :root ដើម្បីងាយស្រួលកែប្រែពណ៌ទាំងមូល ឬធ្វើ Dark Mode។
  • Parent Selector (:has()): ចាប់យកប្រអប់មេដោយផ្អែកលើវត្តមានរបស់ធាតុកូននៅខាងក្នុង។
  • :is() និង :where(): បង្រួមការសរសេរ Selectors ច្រើនឱ្យខ្លីស្អាត។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលបង្កើតប្រព័ន្ធ Design System និងការគ្រប់គ្រង Theme Colors របស់គេហទំព័រ។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ CSS Variables និង :has()):

:root {
  --primary-color: #0284C7;
  --card-radius: 12px;
}

:is(section, article) :is(h1, h2, h3) {
  color: var(--primary-color);
}

/* ចាប់យក .card ណាដែលមានរូបភាព img នៅខាងក្នុង */
.card:has(img) {
  border-radius: var(--card-radius);
  overflow: hidden;
}

5. Explanation (ការពន្យល់កូដ):

  • var(--primary-color) ហៅតម្លៃពណ៌ខៀវដែលបានប្រកាសក្នុង :root មកប្រើប្រាស់។
  • .card:has(img) ដាក់ Style តែទៅលើប្រអប់ .card ណាដែលមានស្លាក <img> ប៉ុណ្ណោះ។

6. Output (លទ្ធផល):

ចំណងជើងទាំងអស់ទទួលបានពណ៌គោលដូចគ្នា ហើយប្រអប់កាតដែលមានរូបភាពនឹងត្រូវបានកាត់ជ្រុងមូលស្វ័យប្រវត្តិ។

7. Practice (លំហាត់អនុវត្ត):

ចូរប្រកាស CSS Variables ចំនួន 4 ក្នុង :root សម្រាប់ពណ៌គោល ពណ៌អក្សរ និងទំហំគម្លាត រួចយកទៅប្រើលើកាតផលិតផល។

HTML5 & CSS3 24. CSS Architecture and Best Practices

24. CSS Architecture, BEM & Best Practices

1. Definition (តើវាជាអ្វី?):

CSS Architecture គឺជាវិធីសាស្ត្ររៀបចំរចនាសម្ព័ន្ធឯកសារ CSS និងការដាក់ឈ្មោះ Class តាមស្តង់ដារអន្តរជាតិ BEM (Block__Element--Modifier) ដើម្បីឱ្យកូដស្អាត មិនជាន់ឈ្មោះគ្នា និងងាយស្រួលថែទាំ។

2. Purpose (រចនាសម្ព័ន្ធនៃក្បួន BEM):

  • Block (.card): ឈ្មោះប្រអប់ Component មេដែលមានលក្ខណៈឯករាជ្យ។
  • Element (.card__title): ឈ្មោះធាតុកូននៅខាងក្នុង Block ភ្ជាប់ដោយសញ្ញា Underscore ពីរ (__)។
  • Modifier (.card--featured): ឈ្មោះសម្រាប់ប្តូរពណ៌ ឬទំហំពិសេស ភ្ជាប់ដោយសញ្ញាដកពីរ (--)។

3. When to Use (តើប្រើនៅពេលណា?):

អនុវត្តនៅគ្រប់ Project អាជីព ដើម្បីឱ្យសមាជិកក្នុងក្រុមអានកូដយល់ភ្លាមៗ និងជៀសវាងការប្រើ !important។

4. Syntax (ឧទាហរណ៍ការសរសេរ HTML និង CSS តាមស្តង់ដារ BEM):

<!-- HTML Structure with BEM Naming -->
<article class="course-card course-card--featured">
  <h3 class="course-card__title">HTML5 & CSS3 Pro</h3>
  <a href="#enroll" class="course-card__btn">ចុះឈ្មោះសិក្សា</a>
</article>

/* CSS Styling */
.course-card { padding: 20px; border: 1px solid #E2E8F0; }
.course-card--featured { border-color: #0284C7; }
.course-card__title { font-size: 1.25rem; font-weight: 700; }

5. Explanation (ការពន្យល់កូដ):

  • គ្រប់ Class ទាំងអស់មានកម្រិត Specificity ស្មើគ្នា (1 Class) ធ្វើឱ្យងាយស្រួលគ្រប់គ្រងបំផុត។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់វគ្គសិក្សាដែលមានស៊ុមពណ៌ខៀវ ចំណងជើងដិត និងប៊ូតុងចុះឈ្មោះតាមស្តង់ដារ Component។

7. Practice (លំហាត់អនុវត្ត):

ចូរសរសេរកូដបង្កើត Alert Component តាមក្បួន BEM ដែលមាន .alert, .alert__text និង .alert--success។

HTML & CSS 01. Introduction to Web Development

01. Introduction to Web Development

1. Definition (និយមន័យ):

Web Development គឺជាការបង្កើត និងអភិវឌ្ឍគេហទំព័រដែលដំណើរការលើ Browser។ ផ្នែកខាងមុខដែលអ្នកប្រើប្រាស់មើលឃើញ និងប្រើប្រាស់ផ្ទាល់ហៅថា Frontend ដែលជាទូទៅត្រូវបានបង្កើតឡើងដោយ ៣ ភាសាគោលគឺ៖ HTML, CSS និង JavaScript ចំណែកផ្នែកខាងក្រោយដែលអ្នកប្រើប្រាស់មើលមិនឃើញហៅថា Backend ដែលមានតួនាទីគ្រប់គ្រងដំណើរការ Logic, Server និងរក្សាទុកទិន្នន័យ (Database)។

2. មុខងារសំខាន់ៗ:

  • HTML (HyperText Markup Language)៖ សម្រាប់បង្កើតគ្រោងឆ្អឹង Website (ពាក្យថា "គ្រោងឆ្អឹង Website" សំដៅទៅលើ៖ មាតិកា និងព័ត៌មានដែលយើងបញ្ចូលដូចជា អត្ថបទ ចំណងជើង រូបភាព Icon ផ្សេងៗ)។
  • CSS (Cascading Style Sheets)៖ សម្រាប់លេង Style ដាក់ពណ៌ ពុម្ពអក្សរ និងរៀបចំធាតុឱ្យមានភាពស្រស់ស្អាត។ បើគ្មាន CSS ទេ គេហទំព័រចេញតែអក្សរសខ្មៅ និងគ្មានទម្រង់រៀបរយ។
  • JavaScript (JS)៖ សម្រាប់បង្កើតចលនា ភាពរស់រវើក និងអន្តរកម្មឆ្លើយតបជាមួយអ្នកប្រើប្រាស់ (ឧ. ពេលចុចប៊ូតុង ផ្ទៀងផ្ទាត់ទិន្នន័យ Form ឬទាញទិន្នន័យពី Server)។
3. Summary (សង្ខេបមេរៀន)៖ HTML សម្រាប់បង្កើតគ្រោងឆ្អឹង Website។ CSS សម្រាប់លេង Style ដាក់ពណ៌ ពុម្ពអក្សរ និងរៀបចំធាតុឱ្យមានភាពស្រស់ស្អាត។ ចំណែក JavaScript ជាអ្នកបង្កើតភាពរស់រវើកទៅលើ Website។

HTML & CSS 02. HTML Document Structure

02. HTML Document Structure (Boilerplate)

1. Definition (និយមន័យ):

HTML Boilerplate គឺជាគ្រោងឆ្អឹងកូដគោលដែលឯកសារ HTML ទាំងអស់ត្រូវតែមានជាដាច់ខាត ដើម្បីឱ្យ Browser ស្គាល់ និងដំណើរការត្រឹមត្រូវ។

2. មុខងារសំខាន់ៗ:

  • <!DOCTYPE html> (ចាប់យកជំនាន់ចុងក្រោយ)៖ ប្រាប់ Browser ឱ្យដំណើរការលើ HTML ជំនាន់ចុងក្រោយ។
  • <html> (មេធំបំផុត - Root)៖ រុំព័ទ្ធកូដទាំងអស់របស់ HTML។
  • <head> (គ្រប់គ្រងព័ត៌មានកំបាំង)៖ ផ្ទុក <meta charset="UTF-8"> (ការពារកុំឱ្យខូចអក្សរខ្មែរ) និង <title>។
  • <body> (ផ្ទុកមាតិកាមើលឃើញ)៖ រាល់កូដរបស់ HTML ត្រូវសរសេរក្នុង body នេះ។
  • ! (Shortcut)៖ ក្នុង VS Code វាយ ! រួចចុច Tab ដើម្បីបង្កើតគ្រោងឆ្អឹងកូដនេះដោយស្វ័យប្រវត្តិ។

3. Syntax (ទម្រង់កូដ):

<!DOCTYPE html>
<html lang="km">
<head>
  <meta charset="UTF-8">
  <title>ទំព័រដើម</title>
</head>
<body>
  <h1>សួស្តីពិភពលោក!</h1>
</body>
</html>

4. Explanation (ការពន្យល់កូដ):

  • lang="km" ប្រាប់កម្មវិធីជំនួយ និង Google ថាទំព័រនេះជាភាសាខ្មែរ។
  • <title> កំណត់ឈ្មោះដែលត្រូវបង្ហាញលើ Tab របស់ Browser។

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500

សួស្តីពិភពលោក!

6. Summary (សង្ខេបមេរៀន)៖ Boilerplate ត្រូវផ្តើមដោយ <!DOCTYPE html> ត្រូវមាន <html> ដែលជាមេសម្រាប់ក្តោបធំលើគេទាំងអស់ បន្ទាប់មាន <head> ផ្ទុកព័ត៌មានកំបាំង និង <body> ផ្ទុកមាតិកាបង្ហាញលើ Browser។

HTML & CSS 03. HTML Text Elements

03. HTML Text Elements, Tag, Element & Attribute

1. Definition (និយមន័យ):

HTML Text Elements ប្រើសម្រាប់រៀបចំអត្ថបទលើគេហទំព័រមានដូចជា៖ <h1> ដល់ <h6>, <p> ដោយផ្អែកលើគ្រឹះស្នូល ៣ គឺ Tag, Element និង Attribute។

2. ចំណុចសំខាន់ៗ:

  • <h1> ដល់ <h6>៖ សម្រាប់ក្តោបចំណងជើងអត្ថបទ។
  • <p>៖ សម្រាប់ក្តោបអត្ថបទ។
  • Text Tags សំខាន់ៗ៖ <strong> ឬ <b> (អក្សរដិត), <em> ឬ <i> (អក្សរទ្រេត), <u> (គូសបន្ទាត់ពីក្រោម), <hr> (បន្ទាត់ផ្តេកខណ្ឌចែក), <sub> (សន្ទស្សន៍ក្រោម), <sup> (ស្វ័យគុណលើ) និង &copy; (©)។
  • Opening Tag៖ សំដៅផ្នែកបើក (ស្លាកបើក)។ ឧ. <p>
  • Closing Tag៖ សំដៅផ្នែកបិទ (ស្លាកបិទ)។ ឧ. </p> (មានសញ្ញាទ្រេត /)។
  • Opening Tag + Closing Tag៖ ពេល Opening Tag និង Closing Tag បូកបញ្ចូលគ្នា គេហៅថា Tag។
  • Content៖ គឺជាអត្ថបទ ឬមាតិកាដែលស្ថិតនៅចន្លោះកណ្តាលរវាង Opening Tag និង Closing Tag។
  • HTML Element៖ គឺកើតចេញពី Opening Tag + Content + Closing Tag បូកបញ្ចូលគ្នាទាំងអស់។
  • Attribute៖ ប្រើសម្រាប់ផ្តល់ព័ត៌មានទៅឱ្យ Tag ហើយវាត្រូវស្ថិតនៅក្នុង Opening Tag ជានិច្ច ក្នុងទម្រង់ name="value" (ដូចជា id, class, title)។

3. Syntax (ទម្រង់កូដ Tag, Element & Attribute):

<!-- Opening Tag (មាន Attribute) + Content + Closing Tag = Element ទាំងមូល -->
<h2 class="heading">រូបមន្តវិទ្យាសាស្ត្រ</h2>

<p title="កថាខណ្ឌ">ទឹកមានរូបមន្ត H<sub>2</sub>O និងសមីការ E = mc<sup>2</sup>។</p>
<p><strong>សំខាន់៖</strong> សូមអានដោយ <em>យកចិត្តទុកដាក់</em>។</p>
<hr>
<p>&copy; 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង</p>

4. Explanation (ការពន្យល់កូដ):

  • <h2 class="heading"> ជា Opening Tag ដែលផ្ទុក Attribute class="heading"។
  • "រូបមន្តវិទ្យាសាស្ត្រ" ជា Content ហើយ </h2> ជា Closing Tag។ ទាំងអស់នេះផ្គុំគ្នាបានជា Heading Element ពេញលេញមួយ។

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500

រូបមន្តវិទ្យាសាស្ត្រ

ទឹកមានរូបមន្ត H2O និងសមីការ E = mc2។

សំខាន់៖ សូមអានដោយ យកចិត្តទុកដាក់។

© 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង
6. Summary (សង្ខេបមេរៀន)៖ Opening Tag + Closing Tag = Tag។ ខាងក្នុង Tag ជា Content ហើយបូកបញ្ចូលគ្នាទាំងអស់បង្កើតបានជា Element។ រីឯ Attribute ស្ថិតក្នុង Opening Tag សម្រាប់ផ្តល់ព័ត៌មានបន្ថែមទៅឱ្យ Tag។

HTML & CSS 04. Links and Navigation

04. Links and Navigation

1. Definition (និយមន័យ):

Tag <a> ប្រើសម្រាប់បង្កើតតំណភ្ជាប់ទៅកាន់គេហទំព័រផ្សេង ឬបញ្ជាឱ្យទូរស័ព្ទបើកផ្ទាំងហៅចេញភ្លាមៗ។

2. មុខងារសំខាន់ៗ:

  • href (Hypertext Reference)៖ ជា Attribute កំណត់អាសយដ្ឋាន URL ឬទីតាំងគោលដៅដែលត្រូវនាំអ្នកប្រើប្រាស់ទៅកាន់នៅពេលចុចលើ Link។ បើគ្មាន href ទេ ស្លាក <a> នឹងក្លាយជាអក្សរធម្មតា ចុចមិនទៅណាឡើយ។
  • target="_blank" (បើក Tab ថ្មី)៖ ប្រើពេលភ្ជាប់ទៅគេហទំព័រខាងក្រៅកុំឱ្យបាត់ទំព័រដើម។
  • rel="noopener" (ការពារសុវត្ថិភាព)៖ ត្រូវតែដាក់ជាមួយ target="_blank" ដើម្បីទប់ស្កាត់ការលួចគ្រប់គ្រង Tab ដើម (Tabnabbing)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើតម៉ឺនុយ Navigation (<nav>), ប៊ូតុង Call-to-Action និងតំណភ្ជាប់ទំនាក់ទំនង។

4. Syntax (ទម្រង់កូដ):

<nav>
  <a href="index.html">ទំព័រដើម</a> |
  <a href="https://w3.org" target="_blank" rel="noopener">W3C ↗</a> |
  <a href="tel:+855979445608">ហៅទូរស័ព្ទ</a>
</nav>

5. Explanation (ការពន្យល់កូដ):

  • href="index.html" ជា Internal Link ផ្លាស់ទីក្នុងគេហទំព័រដដែល។
  • href="tel:..." បញ្ជាឱ្យទូរស័ព្ទបើកផ្ទាំងហៅចេញភ្លាមៗ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
ទំព័រដើម  |  W3C ↗  |  ហៅទូរស័ព្ទ
7. Summary (សង្ខេបមេរៀន)៖ ស្លាក <a> ត្រូវតែមាន href ជាគោលដៅ ហើយត្រូវប្រើគូជាមួយ rel="noopener" ពេលបើកក្នុង Tab ថ្មី។

HTML & CSS 05. HTML Images

05. HTML Images (Absolute & Reference Link)

1. Definition (និយមន័យ):

Tag <img> គឺជា Self-closing Tag (គ្មាន Tag បិទ) ប្រើសម្រាប់ដាក់រូបភាព។

2. វិធីដាក់រូបភាពមាន ២ របៀប:

  • ១. Absolute Link ៖ បញ្ចូលរូបភាពតាមរយៈ Link Address មកពី Browser (ឧ. https://...)។
  • ២. Reference Link ៖ បញ្ចូលរូបភាពដែលមានក្នុង Folder របស់យើងស្រាប់ (ឧ. images/photo.jpg ឬ ../assets/logo.png)។
  • src ៖ សម្រាប់ដាក់ទីតាំងរូបភាព។
  • alt ៖ បង្ហាញអត្ថបទជំនួសពេលរូបភាពផ្ទុកមិនចេញ និងជួយឱ្យស្គាល់រូបភាព។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ Reference Link សម្រាប់រូបភាព Logo ឬ Banner ក្នុងម៉ាស៊ីន និងប្រើ Absolute Link ពេលទាញរូបភាពពី Server ក្រៅ (Cloud/CDN)។

4. Syntax (ទម្រង់កូដ):

<!-- ១. របៀប Absolute Link (តាមរយៈ Link Address ពី Browser) -->
<img src="https://example.com/logo.png" alt="Logo សាលា" width="300">

<!-- ២. របៀប Reference Link (រូបភាពក្នុង Folder របស់យើងស្រាប់) -->
<img src="assets/images/profile.jpg" alt="រូបលោកគ្រូ លាត ប្រុស" width="300">

5. Explanation (ការពន្យល់កូដ):

  • https://... (Absolute Link) រត់ទៅទាញរូបភាពពី Browser ឬ Server លើអ៊ីនធឺណិតមកបង្ហាញ។
  • assets/images/profile.jpg (Reference Link) រកមើលរូបភាពចេញពី Folder ក្នុងម៉ាស៊ីនរបស់យើងផ្ទាល់។
  • width សម្រាប់កំណត់ទំហំទទឹងរូបភាព និង height សម្រាប់កំណត់ កម្ពស់របស់រូបភាព ដែលគិតជា Pixel (ជាទូទៅគេនិយមកំណត់តែ width ដើម្បីរក្សាសមាមាត្រដើម និងកុំឱ្យរូបភាពទាញខូចទ្រង់ទ្រាយ)។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
📁 [Reference Image]
assets/images/profile.jpg
🌐 [Absolute Image]
https://example.com/logo.png
7. Summary (សង្ខេបមេរៀន)៖ រូបភាពដាក់បាន ២ របៀបគឺ Reference Link (ផ្លូវក្នុងម៉ាស៊ីន) និង Absolute Link (Link ពី Browser) ចំណែក src ជាកន្លែងសម្រាប់ដាក់ប្រភពរូបភាព។

HTML & CSS 06. Lists (ol & ul)

06. HTML Lists (Ordered & Unordered)

1. Definition (និយមន័យ):

HTML Lists ប្រើសម្រាប់រៀបចំទិន្នន័យជាបញ្ជី ដែលមាន ២ ប្រភេទចម្បងដែលគេនិយមប្រើបំផុតគឺ៖ បញ្ជីមានលេខរៀង <ol> និងបញ្ជីមានចំណុច (គ្មានលេខរៀង) <ul>។

2. មុខងារសំខាន់ៗ:

  • <ol> (មេបញ្ជីលេខរៀង)៖ សម្រាប់ការងារ ឬចំណាត់ថ្នាក់ដែលប្រកាន់លំដាប់មុនក្រោយ (1, 2, 3...)។
  • <ul> (មេបញ្ជីចំណុច)៖ សម្រាប់ធាតុដែលមិនប្រកាន់លំដាប់ (Bullets) ដូចជាបញ្ជីមុខទំនិញ ឬរបារម៉ឺនុយ Menu។
  • <li> (ក្តោបទិន្នន័យផ្ទាល់)៖ ត្រូវតែនៅខាងក្នុង <ol> ឬ <ul> ជាដាច់ខាត បើគ្មាន <li> ទេ បញ្ជីនឹងមិនចេញជាចំណុច ឬលេខឡើយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បញ្ជីមុខវិជ្ជា បញ្ជីលក្ខណៈពិសេសរបស់ផលិតផល និងការធ្វើ Navigation Bar។

4. Syntax (ទម្រង់កូដ):

<!-- 1. Ordered List (បញ្ជីលេខរៀង) -->
<ol>
  <li>ជំហានទី ១៖ រៀបចំកូដ HTML5</li>
  <li>ជំហានទី ២៖ តុបតែងជាមួយ CSS3</li>
</ol>

<!-- 2. Unordered List (បញ្ជីចំណុច) -->
<ul>
  <li>មុខវិជ្ជា HTML</li>
  <li>មុខវិជ្ជា CSS</li>
</ul>

5. Explanation (ការពន្យល់កូដ):

  • <ol> បង្កើតលេខរៀង 1, 2 ដោយស្វ័យប្រវត្តិ ដោយមិនបាច់វាយដោយដៃឡើយ។
  • <ul> បង្កើតចំណុចដោយស្វ័យប្រវត្តិ ដោយមិនបាច់វាយដោយដៃឡើយ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
  1. ជំហានទី ១៖ រៀបចំកូដ HTML5
  2. ជំហានទី ២៖ តុបតែងជាមួយ CSS3
  • មុខវិជ្ជា HTML
  • មុខវិជ្ជា CSS
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ <ol> ជាបញ្ជីដែលមានលេខរៀង, <ul> ជាបញ្ជីដែលគ្មានលេខរៀង ចំណែក <li> ជាធាតុក្នុងបញ្ជីដែលផ្ទុកទិន្នន័យផ្ទាល់។

HTML & CSS 07. Tables

07. HTML Tables

1. Definition (និយមន័យ):

HTML Table ប្រើសម្រាប់រៀបចំទិន្នន័យជាក្រឡាតារាង ដែលមានជួរឈរ និងជួរដេកត្រឹមត្រូវតាមលំដាប់លំដោយ។

2. មុខងារសំខាន់ៗ:

  • <table> រុំព័ទ្ធតារាងទាំងមូល។
  • <tr> (table row) សម្រាប់ក្តោបជួរដេក។
  • <th> (table header) សម្រាប់ក្តោបទិន្នន័យផ្នែកក្បាលតារាង ("អក្សរដិត" និងតម្រឹមទៅ "កណ្តាល" ដោយស្វ័យប្រវត្តិ)។
  • <td> (table data) សម្រាប់ក្តោបទិន្នន័យធម្មតា ("អក្សរអត់ដិត" និងមិនតម្រឹមទៅ "កណ្តាល" ដោយស្វ័យប្រវត្តិដូច <th> ឡើយ)។
  • colspan សម្រាប់បញ្ចូលក្រឡាច្រើន ចូលជាក្រឡាតែមួយតាមជួរដេក។
  • rowspan សម្រាប់បញ្ចូលក្រឡាច្រើន ចូលជាក្រឡាតែមួយតាមជួរឈរ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់តារាងពិន្ទុសិស្ស តារាងតម្លៃ និងកាលវិភាគសិក្សា (ហាមប្រើសម្រាប់រៀបប្លង់ទំព័រ)។

4. Syntax (ទម្រង់កូដ):

<table border="1" cellpadding="8" cellspacing="0" width="100%">
  <thead>
    <tr>
      <th>វគ្គសិក្សា</th>
      <th>តម្លៃ</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML & CSS</td>
      <td>$45</td>
    </tr>
  </tbody>
</table>

5. Explanation (ការពន្យល់កូដ):

  • border="1" សម្រាប់កំណត់កម្រាស់បន្ទាត់ស៊ុមជុំវិញតារាង។
  • cellpadding="8" សម្រាប់បង្កើតគម្លាតខាងក្នុងប្រអប់ (ចន្លោះពីអក្សរទៅបន្ទាត់ស៊ុម)។
  • cellspacing="0" សម្រាប់លុបគម្លាតចន្លោះប្រអប់នីមួយៗ ឱ្យបន្ទាត់ស៊ុមជាប់គ្នាស្អាត។
  • width="100%" សម្រាប់កំណត់ឱ្យតារាងលាតពេញទទឹងអេក្រង់ 100%។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
វគ្គសិក្សា តម្លៃ
HTML & CSS $45
7. Summary (សង្ខេបមេរៀន)៖ HTML Table រៀបចំទិន្នន័យជាជួរដេក និងជួរឈរ ដោយប្រើ <table> រុំព័ទ្ធតារាងទាំងមូល, <tr> ក្តោបជួរដេក, <th> ក្តោបផ្នែកក្បាលតារាង និង <td> ក្តោបទិន្នន័យធម្មតា។

HTML & CSS 08. HTML Forms

08. HTML Forms

1. Definition (និយមន័យ):

HTML Form គឺជាប្រព័ន្ធប្រមូល និងបញ្ជូនទិន្នន័យពីអ្នកប្រើប្រាស់នៅលើ Browser ទៅកាន់ម៉ាស៊ីន Server។

2. មុខងារសំខាន់ៗ:

  • <form> (ក្តោប Form ទាំងមូល)៖ កំណត់ផ្លូវបញ្ជូន (action) និងវិធីសាស្ត្រ (method="POST")។
  • <input> (ប្រអប់បញ្ចូលទិន្នន័យ)៖ កំណត់ប្រភេទបញ្ចូលដូចជា text, email, password។
  • <label> (ស្លាកសម្គាល់)៖ ប្រើ for ភ្ជាប់ជាមួយ id របស់ Input ជួយឱ្យចុចចំអក្សរក៏លោតចូល Input។
  • placeholder (អក្សរណែនាំ)៖ បង្ហាញអត្ថបទគំរូស្រាលៗនៅក្នុងប្រអប់ Input មុនពេលអ្នកប្រើប្រាស់វាយបញ្ចូល។
  • name (សម្គាល់ទិន្នន័យ)៖ បើ Input គ្មាន Attribute name ទេ ទិន្នន័យក្នុងប្រអប់នោះនឹងមិនត្រូវបានផ្ញើទៅ Server ឡើយ។
  • required (ការពារ)៖ ទប់ស្កាត់កុំឱ្យចុច Submit បានបើប្រអប់ទំនេរ។
  • <fieldset> (ក្តោបក្រុមទិន្នន័យ)៖ ប្រើសម្រាប់បង្កើតស៊ុមព័ទ្ធជុំវិញធាតុក្នុង Form ឱ្យមានរបៀបរៀបរយ។
  • <legend> (ចំណងជើងស៊ុម)៖ ប្រើសម្រាប់ដាក់ចំណងជើងនៅលើបន្ទាត់ស៊ុមរបស់ <fieldset>។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលដែលចង់ប្រមូលទិន្នន័យពីអ្នកប្រើប្រាស់ (ដូចជា Form ចុះឈ្មោះ ឬចូលគណនី)។

4. Syntax (ទម្រង់កូដ):

<form action="/submit" method="post">
  <fieldset>
    <legend>ព័ត៌មានចុះឈ្មោះ</legend>
    <label for="user-email">អ៊ីមែល៖</label>
    <input type="email" id="user-email" name="email" placeholder="you@mail.com" required>
    <button type="submit">ចុះឈ្មោះ</button>
  </fieldset>
</form>

5. Explanation (ការពន្យល់កូដ):

  • <fieldset> និង <legend> ធ្វើការរួមគ្នាដើម្បីបង្កើតស៊ុម និងចំណងជើង «ព័ត៌មានចុះឈ្មោះ» ព័ទ្ធជុំវិញប្រអប់បញ្ចូល។
  • placeholder="you@mail.com" បង្ហាញឧទាហរណ៍ទម្រង់អ៊ីមែលឱ្យអ្នកប្រើប្រាស់ងាយយល់។
  • type="email" ពិនិត្យទម្រង់អ៊ីមែលស្វ័យប្រវត្តិ (ត្រូវតែមានសញ្ញា @)។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500

09. Semantic HTML5 Elements

1. Definition (និយមន័យ):

Semantic HTML5 គឺជាការប្រើប្រាស់ Tag ដែលមានអត្ថន័យច្បាស់លាស់បញ្ជាក់ពីតួនាទីមាតិកា ជំនួសឱ្យការប្រើ <div> គ្រប់កន្លែង។

2. មុខងារសំខាន់ៗ:

  • <header> (ក្តោបផ្នែកក្បាល)៖ ផ្ទុក Logo, ចំណងជើង ឬរបារស្វែងរក។
  • <nav> (ក្តោបផ្នែកម៉ឺនុយ)៖ ផ្ទុកតំណភ្ជាប់ Navigation។
  • <main> (ក្តោបផ្នែកខ្លឹមសារចម្បង)៖ ផ្ទុកមាតិកាសំខាន់បំផុតនៃទំព័រ (ក្នុង ១ ទំព័រត្រូវមានតែមួយគត់)។
  • <article> & <section> (ក្តោបបំណែកមាតិកា)៖ <article> សម្រាប់មាតិកាឯករាជ្យ (ដូចជា Blog) រីឯ <section> សម្រាប់បែងចែកផ្នែក។
  • <aside> (ក្តោបរបារចំហៀង)៖ ផ្ទុកមាតិកាបន្ទាប់បន្សំ ដូចជា Sidebar ឬពាណិជ្ជកម្ម។
  • <footer> (ក្តោបផ្នែកជើងទំព័រ)៖ ផ្ទុកព័ត៌មានរក្សាសិទ្ធិ និងតំណភ្ជាប់បន្ថែម។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរៀបចំគ្រោងឆ្អឹងទំព័រធំៗ ដើម្បីគាំទ្រ SEO (Search Engine Optimization) និង Screen Reader។

4. Syntax (ទម្រង់កូដ):

<header><nav>Main Menu</nav></header>

</main>

  • រចនាសម្ព័ន្ធនេះជួយឱ្យ Search Engine (ម៉ាស៊ីនស្វែងរក) ដឹងច្បាស់ពីចំណុចសំខាន់នៃទំព័ររបស់អ្នក។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
<header> & <nav>
<main> → <article>
<aside>
<footer>
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ Semantic Tags ជំនួស <div> ជួយបង្កើនអត្ថន័យឱ្យកូដស្អាត និងជំរុញចំណាត់ថ្នាក់ SEO (Search Engine Optimization) លើ Google។

HTML & CSS 11. Introduction to CSS3

11. Introduction to CSS3

1. Definition (និយមន័យ):

CSS3 (Cascading Style Sheets) គឺជាភាសាសម្រាប់តុបតែងពណ៌ ពុម្ពអក្សរ គម្លាត និងរៀបចំឱ្យធាតុ HTML មានភាពស្រស់ស្អាត។ របៀបភ្ជាប់ CSS មាន ៣ របៀប៖

  • ១. Inline CSS ៖ សរសេរកូដរចនានៅក្នុង Tag ផ្ទាល់ (ឧ. <p style="...">)។
  • ២. Internal CSS ៖ សរសេរកូដរចនានៅក្នុង Tag <style> នៅខាងក្នុង <head>។
  • ៣. External CSS ៖ សរសេរកូដរចនាក្នុងឯកសារ .css ដាច់ដោយឡែក ហើយភ្ជាប់តាមរយៈ <link> (ពេញនិយមបំផុត)។

2. មុខងារសំខាន់ៗ:

  • Selector (ចាប់ធាតុ)៖ បើគ្មាន Selector ទេ Browser មិនដឹងថាត្រូវយកកូដរចនាទៅដាក់លើ Element ណាមួយឡើយ។
  • Property (លក្ខណៈ)៖ ដូចជា color, background, padding។
  • Value (តម្លៃ)៖ តម្លៃដែលត្រូវផ្តល់ឱ្យ Property (ឧ. red, 16px)។

3. Syntax (ទម្រង់កូដ):

<!-- របៀបភ្ជាប់ External CSS ក្នុង <head> នៃ HTML -->
<link rel="stylesheet" href="style.css">

/* កូដក្នុងឯកសារ style.css */
.card {
  background-color: #E0F2FE;
  color: #0284C7;
  padding: 12px;
  border-radius: 6px;
}

4. Explanation (ការពន្យល់កូដ):

  • <link rel="stylesheet" href="style.css"> ប្រើសម្រាប់ភ្ជាប់ឯកសារ CSS មកតុបតែងទំព័រ HTML។
  • .card ចាប់យកគ្រប់ Element ដែលមាន class="card" មកដាក់ Style ព្រមគ្នា។

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
ប្រអប់អត្ថបទតុបតែងដោយ External CSS (.card)
6. Summary (សង្ខេបមេរៀន)៖ CSS ដំណើរការតាមក្បួន Selector { Property: Value; } ហើយត្រូវភ្ជាប់ជាមួយ HTML តាមរយៈ Tag <link>។

12. CSS Selectors & Pseudo-Classes

1. Definition (និយមន័យ):

CSS Selectors គឺជារបៀបចាប់យកធាតុ HTML មកតុបតែងក្នុង CSS។

2. មុខងារសំខាន់ៗ:

  • element (ចាប់តាមឈ្មោះ Tag)៖ ប្រសិនបើមាន Tag ណាដូចគ្នាវានឹងដំណើរការ style ក្នុង Tag ទាំងនោះ (ឧ. p, h1)។
  • .class (ចាប់តាមឈ្មោះក្នុង Class)៖ ប្រើសញ្ញាចុច . រួចដាក់ឈ្មោះ Class (ឧ. .btn, .card)។
  • #id (ចាប់តាមឈ្មោះក្នុង Id)៖ ប្រើសញ្ញាទ្រុងជ្រូក # រួចដាក់ឈ្មោះ Id (ឧ. #header, #navbar)។
  • :hover (អន្តរកម្ម Mouse)៖ ដំណើរការពេលអ្នកប្រើប្រាស់ដាក់ Mouse ពីលើ (ឧ. .btn:hover, a:hover)។
  • :focus (អន្តរកម្មចុចចូល)៖ ដំណើរការពេលអ្នកប្រើប្រាស់ចុចចូល ដូចជាចុចក្នុងប្រអប់ Input (ឧ. input:focus)។

3. Syntax (ទម្រង់កូដ):

.btn {
  background: #0284C7;
  color: #FFFFFF;
  padding: 6px 14px;
  border-radius: 4px;
}
.btn:hover {
  background: #0369A1; /* ប្តូរពណ៌ពេល Hover */
}

4. Explanation (ការពន្យល់កូដ):

  • .btn កំណត់រូបរាងដើមឱ្យប៊ូតុងទាំងអស់ដែលមាន class="btn"។
  • .btn:hover ជួយឱ្យប៊ូតុងប្តូរពណ៌ឆ្លើយតបពេលអ្នកប្រើដាក់ Mouse លើវា។

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
6. Summary (សង្ខេបមេរៀន)៖ ប្រើ Class Selector (.) ជាចម្បងក្នុងគម្រោង និងប្រើ Pseudo-class (:hover) បង្កើតភាពរស់រវើកដល់ប៊ូតុង។

13. CSS Colors, Backgrounds & Gradients

1. Definition (និយមន័យ):

CSS Colors និង Backgrounds ប្រើសម្រាប់កំណត់ពណ៌អត្ថបទ ពណ៌ផ្ទៃ រូបភាពផ្ទៃខាងក្រោយ និងការលាយពណ៌ Gradients លើ Element។

2. មុខងារសំខាន់ៗ:

  • color (ពណ៌អក្សរ)៖ កំណត់ពណ៌លើអត្ថបទ (ឧ. #0284C7, red)។
  • background-color (ពណ៌ផ្ទៃក្រោយ)៖ កំណត់ពណ៌ផ្ទៃប្រអប់ (ប្រើ HEX ឬ RGBA សម្រាប់ពណ៌ថ្លា)។
  • ក្រុមរូបភាពផ្ទៃក្រោយ (Background Image Group)៖
    • background-image: url("...") ៖ ដាក់រូបភាពផ្ទៃខាងក្រោយ។
    • background-size: cover, contain, px, % ៖ កំណត់ទំហំរូបភាព (ឧ. cover ពង្រីកឱ្យពេញប្រអប់ស្អាតមិនខូចសមាមាត្រ)។
    • background-position: left, center, right ៖ កំណត់ទីតាំងរូបភាព (ឆ្វេង កណ្តាល ឬស្តាំ)។
    • background-repeat: repeat, no-repeat ៖ កំណត់ការរត់ស្ទួននៃរូបភាព (ស្ទួន ឬមិនឱ្យស្ទួន)។
  • linear-gradient() (លាយពណ៌ផ្ទៃក្រោយ)៖ មានរបៀបកំណត់ទិសដៅចំនួន ៤៖
    • to top ៖ រត់ពីក្រោមទៅលើ (Bottom → Top)។
    • to right ៖ រត់ពីឆ្វេងទៅស្តាំ (Left → Right)។
    • to bottom right ៖ រត់បញ្ឆិតពីលើឆ្វេង ទៅក្រោមស្តាំ (Top-Left → Bottom-Right)។
    • to bottom ៖ រត់ពីលើចុះក្រោម (Top → Bottom)។

3. Syntax (ទម្រង់កូដ):

/* ១. ពណ៌អក្សរ និងពណ៌ផ្ទៃក្រោយ */
.card-color {
  background-color: #E0F2FE;
  color: #0369A1;
}

/* ២. រូបភាពផ្ទៃក្រោយ (Background Image) */
.card-image {
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* ៣. លាយពណ៌ផ្ទៃក្រោយ (Linear Gradient) */
.banner {
  background: linear-gradient(to bottom right, #0284C7 0%, #0F172A 100%);
  color: #FFFFFF;
}

5. Summary (សង្ខេបមេរៀន)៖ ប្រើ color សម្រាប់អក្សរ។ ចំណែក background-color, linear-gradient() ឬ background-image ប្រើសម្រាប់កំណត់ផ្ទៃខាងក្រោយ។

14. CSS Typography & Google Fonts

1. Definition (និយមន័យ):

CSS Typography ប្រើសម្រាប់គ្រប់គ្រងទម្រង់ពុម្ពអក្សរ ទំហំ កម្រាស់ ការតម្រឹម និងគម្លាតបន្ទាត់ដើម្បីឱ្យអត្ថបទមានសោភ័ណភាព និងស្រួលអានបំផុត។

2. មុខងារសំខាន់ៗ:

  • font-family (ពុម្ពអក្សរ)៖ កំណត់ប្រភេទពុម្ពអក្សរ (ឧ. 'Kantumruy Pro', sans-serif)។
  • font-size (ទំហំអក្សរ)៖ កំណត់ទំហំអក្សរ (គួរប្រើ rem ជំនួស px)។
  • font-weight (កម្រាស់អក្សរ)៖ កំណត់ភាពស្តើង ឬដិត (400 ធម្មតា, 600 ដិតល្មម, 700 ដិតខ្លាំង)។
  • line-height (គម្លាតជួរ)៖ កំណត់គម្លាតពីជួរមួយទៅជួរមួយ (គួរដាក់ចាប់ពី 1.6 ឡើងសម្រាប់អក្សរខ្មែរ)។
  • text-align (តម្រឹមអក្សរ)៖ កំណត់ទីតាំងអក្សរ (left, center, right, justify)។
  • text-decoration (បន្ទាត់តុបតែងអក្សរ)៖ កំណត់ ឬដកបន្ទាត់លើអត្ថបទ (none, underline, line-through)។
  • letter-spacing (គម្លាតតួអក្សរ)៖ កំណត់ចន្លោះរវាងតួអក្សរនីមួយៗ (ឧ. 2px)។
  • word-spacing (គម្លាតពាក្យ)៖ កំណត់ចន្លោះរវាងពាក្យនីមួយៗ (ឧ. 6px)។

3. Syntax (ទម្រង់កូដ):

body {
  font-family: 'Kantumruy Pro', sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.75;
}
.heading { text-align: center; letter-spacing: 2px; word-spacing: 6px; }
a { text-decoration: none; } /* ដកបន្ទាត់ក្រោម Link */

HTML & CSS 15. CSS Box Model

15. CSS Box Model

1. Definition (និយមន័យ):

CSS Box Model គឺជាគំរូប្រអប់ចតុកោណដែលគ្រប់គ្រងលើទំហំ ស៊ុម និងគម្លាតនៃគ្រប់ធាតុ HTML ទាំងអស់នៅលើគេហទំព័រ។

2. មុខងារសំខាន់ៗ:

  • Content (មាតិកាក្នុង)៖ កន្លែងផ្ទុកអត្ថបទ រូបភាព ឬខ្លឹមសារពិតប្រាកដ។
  • border (ស៊ុមព័ទ្ធជុំវិញ)៖ បន្ទាត់ខណ្ឌចែករវាង Padding និង Margin (ឧ. 2px solid red)។
  • padding (ដកគម្លាតខាងក្នុង)៖ រុញមាតិកាចេញពីស៊ុមខាងក្នុងមាន ៤ តម្លៃ (លើ ស្តាំ ក្រោម ឆ្វេង)
    • Shorthand ៤ ទិស៖ padding: 10px 20px 10px 20px; (លើ ស្តាំ ក្រោម ឆ្វេង)
    • Shorthand ២ ទិស៖ padding: 10px 20px; (លើ-ក្រោម 10px, ឆ្វេង-ស្តាំ 20px)
    • Shorthand ១ ទិស៖ padding: 15px; (ស្មើគ្នាទាំង ៤ ទិស)
  • margin (ដកគម្លាតខាងក្រៅ)៖ រុញប្រអប់ឱ្យឃ្លាតចេញពីប្រអប់ដទៃទៀតមាន ៤ តម្លៃ (លើ ស្តាំ ក្រោម ឆ្វេង)
    • Shorthand ៤ ទិស៖ margin: 10px 20px 10px 20px; (លើ ស្តាំ ក្រោម ឆ្វេង)
    • Shorthand ២ ទិស៖ margin: 10px 20px; (លើ-ក្រោម 10px, ឆ្វេង-ស្តាំ 20px)
    • Shorthand ១ ទិស៖ margin: 15px; (ស្មើគ្នាទាំង ៤ ទិស)
  • បច្ចេកទេសបន្ថែមលើប្រអប់ (Box Properties):
  • margin: 0 auto; (ដាក់ប្រអប់ចំកណ្តាល)៖ រុញប្រអប់ Block ដែលមានទទឹង width ច្បាស់លាស់ឱ្យនៅចំកណ្តាលអេក្រង់តាមអ័ក្សដេក។
  • border-radius (កោងជ្រុងប្រអប់)៖ កាត់ជ្រុងប្រអប់ឱ្យមូលស្អាត (ឧ. 8px ឬ 50%)។
  • box-sizing: border-box; (មេសង្គ្រោះប្លង់ - ខ្វះមិនបាន)៖ បញ្ចូល Padding និង Border ក្នុងទទឹង Width តែមួយ កុំឱ្យប្រអប់រីកធំលើសទំហំកំណត់។

3. Syntax (ទម្រង់កូដ):

.card {
  box-sizing: border-box; /* ការពារកុំឱ្យរីកទំហំលើស 260px */
  width: 260px;
  padding: 12px 16px; /* លើ-ក្រោម 12px | ឆ្វេង-ស្តាំ 16px */
  border: 2px solid #0284C7;
  border-radius: 8px;
  margin: 10px auto; /* លើ-ក្រោម 10px | កណ្តាល auto */
}

Box Model (260px Width)
Content + Padding + Border = 260px គត់
5. Summary (សង្ខេបមេរៀន)៖ Box Model រួមមាន Content, Padding, Border និង Margin ដោយត្រូវប្រើ border-box ជានិច្ចដើម្បីកុំឱ្យទំហំប្រអប់រីកខូចប្លង់។

HTML & CSS 16. CSS Display and Position

16. CSS Display and Position

1. Definition (និយមន័យ):

display កំណត់របៀបបង្ហាញខ្លួនរបស់ Element (ចុះបន្ទាត់ ឬនៅមួយជួរ) រីឯ position កំណត់ទីតាំងជាក់លាក់នៃធាតុនៅលើអេក្រង់ (លើ ក្រោម ឆ្វេង ស្តាំ)។

2. មុខងារសំខាន់ៗ:

  • display (របៀបបង្ហាញ)៖
    • block ៖ ពេញមួយជួរដេក កំណត់ width/height បាន។
    • inline ៖ នៅជាប់គ្នាមួយជួរ កំណត់ width/height មិនបានទេ។
    • inline-block ៖ នៅជាប់គ្នាមួយជួរផង និងកំណត់ width/height បានផង។
    • none ៖ លាក់ Element បាត់ទាំងស្រុងពីទំព័រ។
  • position: relative; (កំណត់ព្រំដែន)៖ ដាក់លើប្រអប់មេ ដើម្បីឃាត់កុំឱ្យកូន absolute រត់ចេញក្រៅប្រអប់។
  • position: absolute; (កំណត់ទីតាំងសេរី)៖ កំណត់ទីតាំងជាក់លាក់ (top, right, bottom, left) ធៀបនឹង relative។
  • position: sticky; (ស្អិតពេល Scroll)៖ ដើរតួធម្មតា តែពេល Scroll ប៉ះទីតាំងកំណត់ (ឧ. top: 0) វានឹងនៅស្អិតជាប់ខាងលើ។
  • position: fixed; & z-index (ជាប់នឹងអេក្រង់ & លំដាប់ស្រទាប់)៖ ជាប់នឹងកញ្ចក់អេក្រង់រហូត ហើយប្រើ z-index ដើម្បីកំណត់ឱ្យនៅលើគេ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ Sticky Header, ប៊ូតុងឆាតអណ្តែតលើអេក្រង់ និងស្លាក Badge លើកាតផលិតផល។

4. Syntax (ទម្រង់កូដ):

.card { position: relative; } /* មេឃាត់កូន */
.badge { position: absolute; top: 8px; right: 8px; }
.navbar { position: sticky; top: 0; z-index: 100; }

Badge នៅជ្រុងលើស្តាំនៃ Card ជានិច្ច
6. Summary (សង្ខេបមេរៀន)៖ ប្រើ position: relative លើប្រអប់មេជានិច្ច ដើម្បីទប់កុំឱ្យធាតុកូន position: absolute រត់រប៉ាត់រប៉ាយពេញអេក្រង់។

HTML & CSS 17. CSS Flexbox Layout

17. CSS Flexbox Layout

1. Definition (និយមន័យ):

CSS Flexbox គឺជាការរៀប Layout (ប្លង់) ជាជួរដេក ឬជួរឈរ ដោយកំណត់ក្នុង div មេ។

2. មុខងារសំខាន់ៗ:

  • display: flex; (ជាមេនៃ Flexbox - ខ្វះមិនបាន)៖ តម្រឹមធាតុចេញជាជួរដេក។ ត្រូវដាក់លើប្រអប់មេជាដាច់ខាត បើគ្មានវាទេ Properties ខាងក្រោមទាំងអស់នឹងមិនដំណើរការឡើយ។
  • flex-direction (កំណត់ទិស)៖ កំណត់ឱ្យរត់ជាជួរដេក (row) ឬជួរឈរ (column)។
  • justify-content (តម្រឹមអ័ក្សដេក)៖ ប្រអប់មេត្រូវមានទទឹង (width) ធំជាងធាតុកូន៖
    • ទីតាំង៖ left ឬ flex-start, center, right ឬ flex-end
    • គម្លាត៖ space-between, space-around, space-evenly
  • align-items (តម្រឹមអ័ក្សឈរ)៖ ប្រអប់មេដាច់ខាតត្រូវមានកម្ពស់ (height) ដើម្បីតម្រឹម (flex-start, center, flex-end, stretch)។
  • flex-wrap: wrap; (ទម្លាក់ចុះបន្ទាត់ស្វ័យប្រវត្តិ)៖ នៅពេលធាតុកូនពេញទទឹងប្រអប់មេ វានឹងធ្លាក់ចុះជួរថ្មីដោយមិនចង្អៀត។
  • gap (ដកគម្លាត)៖ កំណត់គម្លាតស្មើៗគ្នារវាងធាតុកូននីមួយៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់របារ Navbar, ការដាក់ធាតុឱ្យចំកណ្តាលអេក្រង់ និងការរៀបប៊ូតុង ឬកាតមួយជួរ។

4. Syntax (ទម្រង់កូដ):

.navbar {
  display: flex; /* បើកដំណើរការ Flexbox លើប្រអប់មេ */
  justify-content: space-between; /* រុញ Logo ទៅឆ្វេង Menu ទៅស្តាំ */
  align-items: center; /* កណ្តាលជួរឈរស្មើគ្នា */
  gap: 12px;
}

18. CSS Grid Layout

1. Definition (និយមន័យ):

CSS Grid គឺជាការរៀប Layout (ប្លង់) ដោយកំណត់ក្នុង div មេ ដែលអនុញ្ញាតឱ្យអ្នកគ្រប់គ្រងទាំងជួរឈរ (Columns) និងជួរដេក (Rows) ក្នុងពេលតែមួយ។

2. មុខងារសំខាន់ៗ:

  • display: grid; (ជាមេនៃ Grid System - ខ្វះមិនបាន)៖ ត្រូវដាក់លើប្រអប់មេ បើគ្មានវាទេ រាល់ Properties ផ្សេងទៀតរបស់ Grid នឹងមិនដំណើរការឡើយ។
  • grid-template-columns (កំណត់ជួរឈរ)៖ កំណត់ចំនួន និងទទឹងជួរឈរ (ឧ. repeat(3, 1fr) ឬ 200px 1fr)។
  • grid-template-rows (កំណត់ជួរដេក)៖ កំណត់កម្ពស់នៃជួរដេកនីមួយៗ។
  • gap / row-gap / column-gap (គម្លាតក្រឡា)៖ កំណត់គម្លាតរវាងក្រឡានីមួយៗដោយមិនបាច់ប្រើ Margin។
  • grid-column: span 2; & grid-row: span 2; (បញ្ចូលក្រឡា)៖ ពង្រីកក្រឡាមួយឱ្យលាតសន្ធឹងលើ ២ ជួរឈរ ឬ ២ ជួរដេក។

3. Flexbox vs Grid (ប្រៀបធៀបការប្រើប្រាស់):

  • Flexbox៖ ប្រើនៅពេលធាតុមាន ប្រវែងមិនស្មើគ្នា (ដូចជា Navbar, ...)។
  • CSS Grid៖ ប្រើនៅពេលធាតុមាន ប្រវែងស្មើគ្នា (ដូចជា Card, ...) និងការធ្វើ Responsive។

4. Syntax (ទម្រង់កូដ):

.grid-container {
  display: grid; /* បើកដំណើរការ Grid System (ខ្វះមិនបាន) */
  grid-template-columns: repeat(3, 1fr); /* ចែក ៣ ជួរឈរស្មើគ្នា */
  gap: 12px; /* គម្លាតរវាងក្រឡា ១២px */
}
.box-wide { grid-column: span 2; }

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
Grid 1 (1fr)
Grid 2 (1fr)
Grid 3 (1fr)
6. Summary (សង្ខេបមេរៀន)៖ display: grid; ជាមេបើកផ្លូវ បន្ទាប់មកទើបប្រើ grid-template-columns កំណត់ជួរឈរ និង gap កំណត់គម្លាត។

HTML & CSS 19. Responsive Design (Media Queries)

19. Responsive Design (Media Queries)

1. Definition (និយមន័យ):

Responsive គឺជាការរៀបចំគេហទំព័រឱ្យមានភាពបត់បែនដោយស្វ័យប្រវត្តិ តាមទំហំអេក្រង់នីមួយៗដែលយើងចង់បាន។

2. មុខងារសំខាន់ៗ:

  • @media (កំណត់លក្ខខណ្ឌ)៖ បញ្ជាឱ្យ Browser ដំណើរការកូដ CSS តែនៅពេលអេក្រង់ធ្លាក់ក្នុងលក្ខខណ្ឌកំណត់។
  • min-width (Mobile-First)៖ ដំណើរការនៅពេលអេក្រង់មានទំហំ ចាប់ពីប៉ុណ្ណឹងឡើងទៅ (ឧ. min-width: 768px គឺចាប់ពី Tablet ឡើងទៅកុំព្យូទ័រ)។
  • max-width (Desktop-First)៖ ដំណើរការនៅពេលអេក្រង់មានទំហំ ត្រឹមប៉ុណ្ណឹងចុះក្រោម (ឧ. max-width: 768px គឺសម្រាប់តែអេក្រង់ Tablet និងទូរស័ព្ទដៃប៉ុណ្ណោះ)។
  • ខ្នាតទំហំស្តង់ដារ (Breakpoints)៖ ទូរស័ព្ទ (≤ 576px), Tablet (≤ 768px), Laptop (≤ 992px), Desktop (≥ 1200px)។
  • <meta name="viewport"> (បើកផ្លូវលើទូរស័ព្ទ)៖ ត្រូវតែមានក្នុង <head> បើគ្មានវាទេ Browser លើទូរស័ព្ទនឹងមិនស្គាល់ Media Query ឡើយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលធ្វើ Website ជាក់ស្តែង។ បើមិនកំណត់ទេ គេហទំព័រអាចមើលស្អាតតែលើកុំព្យូទ័រប៉ុណ្ណោះ ហើយពេលបើកលើទូរស័ព្ទដៃនឹងខូចទ្រង់ទ្រាយ។

4. Syntax (ទម្រង់កូដប្រើប្រាស់ max-width):

/* ១. ប្លង់លំនាំដើមសម្រាប់កុំព្យូទ័រ (Desktop: បង្ហាញ ៣ ជួរឈរ) */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* ២. អេក្រង់ត្រឹម ៧៦៨px ចុះក្រោម (Tablet & Mobile: បង្រួមមកសល់ ១ ជួរឈរ) */
@media (max-width: 768px) {
  .container {
    grid-template-columns: 1fr;
  }
}

6. Summary (សង្ខេបមេរៀន)៖ ត្រូវចាំថា min-width ដំណើរការពីទំហំកំណត់ ឡើងទៅលើ (Mobile-First) រីឯ max-width ដំណើរការពីទំហំកំណត់ ចុះមកក្រោម (Desktop-First) សម្រាប់កែសម្រួលប្លង់លើទូរស័ព្ទដៃ។

HTML & CSS 20. CSS Units & Math Functions

20. CSS Units & Math Functions

1. Definition (និយមន័យ):

CSS Units គឺជាខ្នាតរង្វាស់ទំហំ រួមមានខ្នាតថេរ (px), ខ្នាតធៀប (%, em, rem, vw, vh) និងអនុគមន៍គណនាទំនើបសម្រាប់ Responsive។

2. មុខងារសំខាន់ៗ:

  • px (Pixels - ខ្នាតថេរ)៖ ទំហំថេរមិនប្រែប្រួលតាមអេក្រង់ (ល្អសម្រាប់ border ឬ border-radius)។
  • % (Percentage)៖ គិតជាភាគរយធៀបនឹងទំហំរបស់ប្រអប់មេផ្ទាល់។
  • rem & em (ខ្នាតធៀបពុម្ពអក្សរ)៖ rem ធៀបនឹង Root HTML (1rem = 16px) រីឯ em ធៀបនឹងទំហំអក្សររបស់ប្រអប់មេ។
  • vw & vh (Viewport Units)៖ 100vw = ពេញទទឹងកញ្ចក់អេក្រង់, 100vh = ពេញកម្ពស់កញ្ចក់អេក្រង់។
  • clamp(min, preferred, max) (បង្រួមពង្រីកស្វ័យប្រវត្តិ)៖ កំណត់ទំហំអក្សរឱ្យប្រែប្រួលរវាងតម្លៃតូចបំផុត និងធំបំផុតតាមអេក្រង់។
  • calc() & min() (អនុគមន៍គណនា)៖ គណនាច្របល់ខ្នាតចូលគ្នា (ឧ. calc(100vh - 70px))។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ rem សម្រាប់ទំហំអក្សរទូទៅ, vh សម្រាប់ Hero Section ពេញអេក្រង់ និង clamp() សម្រាប់ចំណងជើងធំៗ។

4. Syntax (ទម្រង់កូដ):

.hero-title {
  font-size: clamp(1.2rem, 2.5vw + 0.5rem, 2.2rem);
}
.hero-banner {
  min-height: calc(100vh - 70px);
}
.container {
  width: min(100% - 2rem, 1140px);
}

6. Summary (សង្ខេបមេរៀន)៖ ប្រើ rem សម្រាប់ទំហំអក្សរ និងប្រើ clamp() បង្កើត Fluid Typography ដោយមិនបាច់សរសេរ Media Query ច្រើនដង។

HTML & CSS 21. CSS Transitions and Transforms

21. CSS Transitions and Transforms

1. Definition (និយមន័យ):

transition បង្កើតការផ្លាស់ប្តូរចលនាឱ្យលឿន ឬយឺត។ រីឯ transform ប្រើសម្រាប់រំកិល ពង្រីក បង្វិល ឬផ្អៀងរូបរាង Element។

2. មុខងារសំខាន់ៗ:

  • transition (ពន្យឺតចលនា - ខ្វះមិនបាន)៖ កំណត់រយៈពេល និងល្បឿនប្តូរ (ឧ. all 0.3s ease) បើគ្មានវាទេ ចលនានឹងកន្ត្រាក់ភ្លាមៗ។
  • transform: translate(x, y) (រំកិលទីតាំង)៖ រំកិលប្រអប់តាមអ័ក្សដេក ឬឈរ (ឧ. translateY(-5px) លើកឡើងលើពេល Hover)។
  • transform: scale(1.05) (ពង្រីក/បង្រួម)៖ ពង្រីកប្រអប់ ឬរូបភាពឱ្យធំបន្តិច (> 1 ពង្រីក, < 1 បង្រួម)។
  • transform: rotate(45deg) (បង្វិល)៖ បង្វិលធាតុតាមមុំដឺក្រេ។
  • transform: skew(10deg) (ផ្អៀង)៖ ទាញរូបរាងប្រអប់ឱ្យផ្អៀង។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើតចលនារលូនពេលដាក់ Mouse ពីលើ (:hover) ប៊ូតុង រូបភាព និងកាតផលិតផល។

4. Syntax (ទម្រង់កូដ):

.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease; /* រយៈពេល ០.៣ វិនាទី */
}
.card:hover {
  transform: translateY(-5px) scale(1.02); /* អណ្តែតឡើងលើ និងរីកធំបន្តិច */
}

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
ដាក់ Mouse លើប៊ូតុង (Hover Smooth Animation)
6. Summary (សង្ខេបមេរៀន)៖ ត្រូវដាក់ transition លើ Element មេជាមុន ទើបពេល Hover ជាមួយ transform ចេញមកមានចលនារលូន។

HTML & CSS 22. CSS Animations (@keyframes)

22. CSS Animations (@keyframes)

1. Definition (និយមន័យ):

CSS Animations គឺជាការបង្កើតចលនាស្វ័យប្រវត្តិច្រើនដំណាក់កាលដោយមិនបាច់រង់ចាំការដាក់ Mouse ពីលើឡើយ។

2. មុខងារសំខាន់ៗ:

  • @keyframes (បង្កើតដំណាក់កាលចលនា)៖ តម្លៃចាប់ពី 0% (from) ដល់ 100% (to)។
  • animation-name (ឈ្មោះចលនា)៖ ហៅឈ្មោះ @keyframes ដែលបានបង្កើតមកប្រើ។
  • animation-duration (រយៈពេលចលនា)៖ កំណត់ថាចលនា ១ ជុំត្រូវរត់ប៉ុន្មានវិនាទី (ឧ. 1s, 2s)។
  • animation-timing-function (ល្បឿនចលនា)៖ linear (ល្បឿនស្មើ), ease-in-out (យឺតដើម-ចុង)។
  • animation-iteration-count (ចំនួនជុំ)៖ កំណត់ចំនួនដង ឬប្រើ infinite ដើម្បីឱ្យវិលជុំមិនឈប់។
  • animation-direction (ទិសដៅចលនា)៖ normal (ទៅមុខ) ឬ alternate (ទៅមកឆ្លាស់គ្នា)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ Loading Spinners, ភ្លើងលោត Pulse និង Effect បង្ហាញទំព័រដំបូង។

4. Syntax (ទម្រង់កូដ):

@keyframes spin {
  100% { transform: rotate(360deg); }
}
.spinner {
  width: 26px;
  height: 26px;
  border: 3px solid #E0F2FE;
  border-top-color: #0284C7;
  border-radius: 50%;
  animation: spin 1s linear infinite; /* Shorthand */
}

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/spinner.html
កំពុងដំណើរការ (Loading Spinner...)
6. Summary (សង្ខេបមេរៀន)៖ បង្កើតចលនាដោយប្រកាស @keyframes រួចហៅប្រើក្នុង Element តាមរយៈ Property animation។

HTML & CSS 23. Advanced CSS (Variables, :is, :has)

23. Advanced CSS (Variables, :is, :has)

1. Definition (និយមន័យ):

មុខងារ CSS កម្រិតខ្ពស់រួមមាន CSS Variables (Custom Properties) និង Selectors ជំនាន់ថ្មីជួយឱ្យកូដខ្លី ឆ្លាតវៃ និងងាយស្រួលគ្រប់គ្រងប្រព័ន្ធពណ៌។

2. មុខងារសំខាន់ៗ:

  • :root (កន្លែងផ្ទុកអថេរសកល)៖ កន្លែងប្រកាស CSS Variables (ផ្តើមដោយ --) ដើម្បីហៅប្រើបានគ្រប់កន្លែង។
  • var(--name) (ទាញតម្លៃអថេរមកប្រើ)៖ ហៅពណ៌ ឬទំហំមកប្រើ បើចង់ប្តូរ Theme ដូរតែក្នុង :root មួយកន្លែងគឺរួចរាល់។
  • :has() (ចាប់ប្រអប់មេ - Parent Selector)៖ ចាប់ស្ទីលលើប្រអប់មេដោយផ្អែកលើវត្តមានរបស់ធាតុកូនខាងក្នុង (ឧ. .card:has(img))។
  • :is() & :where() (បង្រួម Selector)៖ សរសេរកាត់បន្ថយការសរសេរ Selector វែងៗផ្ទួនគ្នាឱ្យនៅខ្លី។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើត Dark/Light Mode និងគ្រប់គ្រងប្រព័ន្ធពណ៌ Design System ក្នុងគម្រោងធំៗ។

4. Syntax (ទម្រង់កូដ):

:root {
  --primary-color: #0284C7; /* ប្រកាសអថេរពណ៌គោល */
}
.card {
  border: 2px solid var(--primary-color);
  padding: 10px;
}
:is(h1, h2, h3) {
  color: var(--primary-color); /* បង្រួម Selector */
}

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500
Card Styled with CSS Variable: var(--primary-color)
6. Summary (សង្ខេបមេរៀន)៖ CSS Variables ប្រកាសក្នុង :root ជួយឱ្យការកែប្រែពណ៌ប្រព័ន្ធទាំងមូលរហ័សទាន់ចិត្ត និងងាយស្រួលធ្វើ Dark Mode។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 26
HTML & CSS 24. CSS Architecture & BEM Methodology

24. CSS Architecture & BEM Methodology

1. Definition (និយមន័យ):

BEM (Block__Element--Modifier) គឺជាស្តង់ដារអន្តរជាតិនៃការដាក់ឈ្មោះ Class ក្នុង CSS ដើម្បីកុំឱ្យជាន់ឈ្មោះគ្នា និងងាយស្រួលធ្វើការងារជាក្រុម។

2. មុខងារសំខាន់ៗ:

  • Block (.card) — ប្រអប់ឯករាជ្យ៖ ប្រអប់ធំដែលតំណាងឱ្យ Component មួយទាំងមូល (ឧ. .navbar, .card)។
  • Element (.card__title) — ធាតុកូនខាងក្នុង៖ ធាតុកូនក្នុង Block ភ្ជាប់ដោយសញ្ញា Underscore ពីរ (__)។
  • Modifier (.card--featured) — កំណែពិសេស៖ ប្រើសម្រាប់ប្តូរពណ៌ ឬទំហំ ភ្ជាប់ដោយសញ្ញាដកពីរ (--)។
  • ការអនុវត្តល្អបំផុត (Best Practices)៖ ជៀសវាងការប្រើ !important, កុំសរសេរ Selector ជ្រៅពេក និងបែងចែកកូដតាមផ្នែក។

3. When to Use (តើប្រើនៅពេលណា?):

អនុវត្តក្នុងគម្រោងធំៗ ឬពេលធ្វើការជាក្រុម ដើម្បីជៀសវាងការជាន់ឈ្មោះ Class និងការប្រើ !important។

4. Syntax (ទម្រង់កូដ):

<!-- ១. HTML Structure -->
<article class="card card--featured">
  <h3 class="card__title">HTML & CSS Pro</h3>
  <button class="card__btn">ចុះឈ្មោះ</button>
</article>

/* ២. CSS Styling */
.card--featured { border: 2px solid #0284C7; }
.card__title { color: #0F172A; }

5. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/bem.html
HTML & CSS Pro (.card--featured)
6. Summary (សង្ខេបមេរៀន)៖ ក្បួន BEM (Block, Element, Modifier) ជួយឱ្យកូដ CSS មានរបៀបរៀបរយខ្ពស់ មិនជាន់ឈ្មោះគ្នា និងងាយពង្រីកគម្រោងទៅមុខ។

HTML & CSS 01. Introduction to Web Development

01. Introduction to Web Development

1. Definition (តើវាជាអ្វី?):

Web Development គឺជាការបង្កើតគេហទំព័រដែលដំណើរការលើ Browser។ ផ្នែកខាងមុខហៅថា Frontend (HTML បង្កើតគ្រោងឆ្អឹង, CSS តុបតែងរចនា) ចំណែកផ្នែកម៉ាស៊ីនមេហៅថា Backend។

2. មុខងារសំខាន់ៗ៖

  • HTML (តួមេគ្រោងឆ្អឹង)៖ បើគ្មាន HTML ទេ Browser គ្មានអ្វីត្រូវគូស ឬបង្ហាញឡើយ។
  • CSS (តួមេរចនា)៖ បើគ្មាន CSS ទេ គេហទំព័រចេញតែអក្សរសខ្មៅ និងគ្មានទម្រង់រៀបរយ។
  • Element & Attribute៖ Element កំណត់ប្រភេទមាតិកា រីឯ Attribute ផ្តល់ព័ត៌មានបន្ថែមដូចជា id ឬ class សម្រាប់ឱ្យ CSS ចាប់យកទៅរចនា។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់នៅរាល់ពេលចាប់ផ្តើមសាងសង់គេហទំព័រគ្រប់ប្រភេទ។

4. Syntax (ទម្រង់កូដ):

<h1 class="title">សូមស្វាគមន៍មកកាន់ HTML & CSS!</h1>
<p>HTML កំណត់គ្រោងឆ្អឹង រីឯ CSS តុបតែងរូបរាង។</p>

5. Explanation (ការពន្យល់កូដ):

  • <h1> ជាស្លាកបង្កើតចំណងជើងធំបំផុតនៅលើទំព័រ។
  • class="title" ដាក់ឈ្មោះសម្គាល់ដើម្បីងាយស្រួលហៅក្នុង CSS។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/index.html

សូមស្វាគមន៍មកកាន់ HTML & CSS!

HTML កំណត់គ្រោងឆ្អឹង រីឯ CSS តុបតែងរូបរាង។

7. Summary (សង្ខេបមេរៀន)៖ HTML ជាគ្រឹះនៃមាតិកា ចំណែក CSS ជាអ្នកកំណត់សោភ័ណភាព បើខ្វះមួយណាគេហទំព័រក៏មិនអាចពេញលេញបានដែរ។

HTML & CSS 02. HTML Document Structure

02. HTML Document Structure (Boilerplate)

1. Definition (តើវាជាអ្វី?):

HTML Boilerplate គឺជាគ្រោងឆ្អឹងកូដគោលដែលឯកសារ HTML ទាំងអស់ត្រូវតែមានជាដាច់ខាត ដើម្បីឱ្យ Browser ស្គាល់ និងដំណើរការត្រឹមត្រូវ។

2. មុខងារសំខាន់ៗ៖

  • <!DOCTYPE html> (មេកំណត់ជំនាន់)៖ ប្រាប់ Browser ឱ្យដំណើរការតាមស្តង់ដារ HTML5 បើអត់ដាក់អាចខូចប្លង់ចាស់គំរឹល (Quirks Mode)។
  • <html> (មេធំបំផុត - Root)៖ រុំព័ទ្ធកូដទាំងអស់ក្នុងឯកសារ។
  • <head> (មេគ្រប់គ្រងព័ត៌មានកំបាំង)៖ ផ្ទុក <meta charset="UTF-8"> (ការពារកុំឱ្យខូចអក្សរខ្មែរ) និង <title>។
  • <body> (មេផ្ទុកមាតិកាមើលឃើញ)៖ គ្រប់អក្សរ រូបភាព និងប៊ូតុងត្រូវតែសរសេរក្នុងនេះ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលបង្កើត File HTML ថ្មី (ក្នុង VS Code វាយ ! រួចចុច Tab)។

4. Syntax (ទម្រង់កូដ):

<!DOCTYPE html>
<html lang="km">
<head>
  <meta charset="UTF-8">
  <title>ទំព័រដើម</title>
</head>
<body>
  <h1>សួស្តីពិភពលោក!</h1>
</body>
</html>

5. Explanation (ការពន្យល់កូដ):

  • lang="km" ប្រាប់កម្មវិធីជំនួយ និង Google ថាទំព័រនេះជាភាសាខ្មែរ។
  • <title> កំណត់ឈ្មោះដែលត្រូវបង្ហាញលើ Tab របស់ Browser។

6. Output (លទ្ធផលនៅលើ Browser):

🌐 ទំព័រដើម - https://localhost:5500/

សួស្តីពិភពលោក!

7. Summary (សង្ខេបមេរៀន)៖ Boilerplate ត្រូវផ្តើមដោយ <!DOCTYPE html> មាន <head> ផ្ទុកការកំណត់ និង <body> ផ្ទុកមាតិកាបង្ហាញលើអេក្រង់។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 5
HTML & CSS 03. HTML Text Elements

03. HTML Text Elements, Tag, Element & Attribute

1. Definition (តើវាជាអ្វី?):

HTML Text Elements ប្រើសម្រាប់រៀបចំអត្ថបទលើគេហទំព័រ (ដូចជា <h1> ដល់ <h6>, <p>) ដោយផ្អែកលើគ្រឹះស្នូល ៣ គឺ Tag, Element និង Attribute។

2. Tag, Content, Element & Attribute (ចំណុចគន្លឹះសំខាន់បំផុត):

  • Opening Tag & Closing Tag៖ ស្លាកបើកគឺ <tag> រីឯស្លាកបិទគឺ </tag> (មានសញ្ញាទ្រេត /)។ ពេល Opening Tag និង Closing Tag បូកបញ្ចូលគ្នា គេហៅថា Tag។
  • Content៖ គឺជាអត្ថបទ ឬមាតិកាដែលស្ថិតនៅចន្លោះកណ្តាលរវាង Opening Tag និង Closing Tag។
  • HTML Element៖ គឺកើតចេញពី Opening Tag + Content + Closing Tag បូកបញ្ចូលគ្នាទាំងអស់។
  • Attribute៖ ប្រើសម្រាប់ផ្តល់ព័ត៌មានទៅឱ្យ Tag ហើយវាត្រូវស្ថិតនៅក្នុង Opening Tag ជានិច្ច ក្នុងទម្រង់ name="value" (ដូចជា id, class, title)។
  • Text Tags សំខាន់ៗ៖ <strong> (អក្សរដិតសង្កត់ន័យ), <em> (អក្សរទ្រេត), <sub> (សន្ទស្សន៍ក្រោម), <sup> (ស្វ័យគុណលើ) និង &copy; (©)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលសរសេរខ្លឹមសារអត្ថបទ ចំណងជើង កថាខណ្ឌ និងរូបមន្តគណិតវិទ្យា/គីមីវិទ្យា។

4. Syntax (ទម្រង់កូដ Tag, Element & Attribute):

<!-- Opening Tag (មាន Attribute) + Content + Closing Tag = Element ទាំងមូល -->
<h2 class="heading">រូបមន្តវិទ្យាសាស្ត្រ</h2>

<p title="កថាខណ្ឌ">ទឹកមានរូបមន្ត H<sub>2</sub>O និងសមីការ E = mc<sup>2</sup>។</p>
<p><strong>សំខាន់៖</strong> សូមអានដោយ <em>យកចិត្តទុកដាក់</em>។</p>
<hr>
<p>&copy; 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង</p>

5. Explanation (ការពន្យល់កូដ):

  • <h2 class="heading"> ជា Opening Tag ដែលផ្ទុក Attribute class="heading"។
  • "រូបមន្តវិទ្យាសាស្ត្រ" ជា Content ហើយ </h2> ជា Closing Tag។ ទាំងអស់នេះផ្គុំគ្នាបានជា Heading Element ពេញលេញមួយ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/text.html

រូបមន្តវិទ្យាសាស្ត្រ

ទឹកមានរូបមន្ត H2O និងសមីការ E = mc2។

សំខាន់៖ សូមអានដោយ យកចិត្តទុកដាក់។

© 2026 រក្សាសិទ្ធិគ្រប់យ៉ាង
7. Summary (សង្ខេបមេរៀន)៖ Opening Tag + Closing Tag = Tag។ ខាងក្នុង Tag ជា Content ហើយបូកបញ្ចូលគ្នាទាំងអស់បង្កើតបានជា Element។ រីឯ Attribute ស្ថិតក្នុង Opening Tag សម្រាប់ផ្តល់ព័ត៌មានបន្ថែម។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 6
HTML & CSS 04. Links and Navigation

04. Links and Navigation

1. Definition (តើវាជាអ្វី?):

ស្លាក <a> (Anchor Element) ប្រើសម្រាប់បង្កើតតំណភ្ជាប់ (Hyperlink) ដើម្បីផ្លាស់ទីរវាងទំព័រ ភ្ជាប់ទៅគេហទំព័រក្រៅ ឬផ្ញើអ៊ីមែល និងទូរស័ព្ទ។

2. មុខងារសំខាន់ៗ៖

  • href (មេគោលដៅ - ខ្វះមិនបាន)៖ បើគ្មាន href ទេ ស្លាក <a> នឹងក្លាយជាអក្សរធម្មតា ចុចមិនទៅណាឡើយ។
  • target="_blank" (បើក Tab ថ្មី)៖ ប្រើពេលភ្ជាប់ទៅគេហទំព័រខាងក្រៅកុំឱ្យបាត់ទំព័រដើម។
  • rel="noopener" (ការពារសុវត្ថិភាព)៖ ត្រូវតែដាក់ជាមួយ target="_blank" ដើម្បីទប់ស្កាត់ការលួចគ្រប់គ្រង Tab ដើម (Tabnabbing)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើតម៉ឺនុយ Navigation (<nav>), ប៊ូតុង Call-to-Action និងតំណភ្ជាប់ទំនាក់ទំនង។

4. Syntax (ទម្រង់កូដ):

<nav>
  <a href="index.html">ទំព័រដើម</a> |
  <a href="https://w3.org" target="_blank" rel="noopener">W3C ↗</a> |
  <a href="tel:+855979445608">ហៅទូរស័ព្ទ</a>
</nav>

5. Explanation (ការពន្យល់កូដ):

  • href="index.html" ជា Internal Link ផ្លាស់ទីក្នុងគេហទំព័រដដែល។
  • href="tel:..." បញ្ជាឱ្យទូរស័ព្ទបើកផ្ទាំងហៅចេញភ្លាមៗ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/nav.html
ទំព័រដើម  |  W3C ↗  |  ហៅទូរស័ព្ទ
7. Summary (សង្ខេបមេរៀន)៖ ស្លាក <a> ត្រូវតែមាន href ជាគោលដៅ ហើយត្រូវប្រើគូជាមួយ rel="noopener" ពេលបើកក្នុង Tab ថ្មី។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 7
HTML & CSS 05. HTML Images

05. HTML Images (Absolute & Relative Path)

1. Definition (តើវាជាអ្វី?):

ស្លាក <img> គឺជា Empty/Void Element (គ្មាន Tag បិទឡើយ) ប្រើសម្រាប់បង្កប់ និងបង្ហាញរូបភាពនៅលើទំព័រគេហទំព័រ។

2. Two Ways to Insert Images (វិធីដាក់រូបភាពទាំង ២ របៀប):

  • ១. Relative Path (ផ្លូវយោងក្នុងគម្រោងផ្ទាល់)៖ យោងតាមទីតាំង Folder ក្នុងម៉ាស៊ីន ឬ Hosting របស់យើង (ឧ. images/photo.jpg ឬ ../assets/logo.png)។ វិធីនេះពេញនិយមបំផុតសម្រាប់រូបភាពក្នុងវេបសាយផ្ទាល់ ព្រោះទោះបីប្តូរ Domain ក៏រូបភាពមិនងាយដាច់ដែរ។
  • ២. Absolute Path/Link (ផ្លូវពេញលេញពីអ៊ីនធឺណិត)៖ ប្រើប្រាស់ URL ពេញលេញដែលផ្តើមដោយ https://... ស្រង់ចេញពីគេហទំព័រខាងក្រៅ។ គុណវិបត្តិគឺបើសាមីគេហទំព័រដើមលុបរូបភាពចោល នោះរូបភាពលើវេបសាយយើងក៏នឹងដាច់តាមដែរ។
  • src (មេប្រភព - ខ្វះមិនបាន)៖ ប្រាប់ពីទីតាំងរូបភាព បើគ្មានវាទេ Browser គ្មានអ្វីបង្ហាញឡើយ។
  • alt (មេអត្ថបទជំនួស)៖ បង្ហាញអត្ថបទជំនួសពេលរូបភាពផ្ទុកមិនចេញ និងជួយឱ្យស្គាល់រូបភាព។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ Relative Path សម្រាប់រូបភាព Logo ឬ Banner ក្នុងម៉ាស៊ីន និងប្រើ Absolute Link ពេលទាញរូបភាពពី Server ក្រៅ (Cloud/CDN)។

4. Syntax (ទម្រង់កូដ):

<!-- ១. របៀប Relative Path (យោងក្នុង Folder គម្រោង) -->
<img src="assets/images/profile.jpg" alt="រូបលោកគ្រូ លាត ប្រុស" width="300">

<!-- ២. របៀប Absolute Link (តំណពេញលេញពីអ៊ីនធឺណិត) -->
<img src="https://example.com/logo.png" alt="Logo សាលា" width="300">

5. Explanation (ការពន្យល់កូដ):

  • assets/images/profile.jpg រកមើលរូបភាពចេញពី Folder ក្នុងម៉ាស៊ីនផ្ទាល់។
  • https://... រត់ទៅទាញរូបភាពពី Server លើអ៊ីនធឺណិតមកបង្ហាញ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/images.html
📁 [Relative Image]
assets/images/profile.jpg
🌐 [Absolute Image]
https://example.com/logo.png
7. Summary (សង្ខេបមេរៀន)៖ រូបភាពដាក់បាន ២ របៀបគឺ Relative (ផ្លូវក្នុងម៉ាស៊ីន) និង Absolute (Link ពេញលេញ) ដោយត្រូវតែមាន src ជាប្រភព និង alt ជាអត្ថបទជំនួសជាដាច់ខាត។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 8
HTML & CSS 06. Lists (ol & ul)

06. HTML Lists (Ordered & Unordered)

1. Definition (តើវាជាអ្វី?):

HTML Lists ប្រើសម្រាប់រៀបចំទិន្នន័យជាបញ្ជី ដែលមាន ២ ប្រភេទចម្បងដែលគេនិយមប្រើបំផុតគឺ៖ បញ្ជីមានលេខរៀង (<ol>) និងបញ្ជីមានចំណុច (<ul>)។

2. មុខងារសំខាន់ៗ៖

  • <ol> (មេបញ្ជីលេខរៀង)៖ សម្រាប់ជំហានការងារ ឬចំណាត់ថ្នាក់ដែលប្រកាន់លំដាប់មុនក្រោយ (1, 2, 3...)។
  • <ul> (មេបញ្ជីចំណុច)៖ សម្រាប់ធាតុដែលមិនប្រកាន់លំដាប់ (Bullets) ដូចជាបញ្ជីមុខទំនិញ ឬរបារម៉ឺនុយ Menu។
  • <li> (កូនបញ្ជី - ខ្វះមិនបាន)៖ ត្រូវតែនៅខាងក្នុង <ol> ឬ <ul> ជាដាច់ខាត បើគ្មាន <li> ទេ បញ្ជីនឹងមិនចេញជាចំណុច ឬលេខឡើយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បញ្ជីមុខវិជ្ជា បញ្ជីលក្ខណៈពិសេសរបស់ផលិតផល និងការធ្វើ Navigation Bar។

4. Syntax (ទម្រង់កូដ):

<!-- 1. Ordered List (បញ្ជីលេខរៀង) -->
<ol>
  <li>ជំហានទី ១៖ រៀបចំកូដ HTML5</li>
  <li>ជំហានទី ២៖ តុបតែងជាមួយ CSS3</li>
</ol>

<!-- 2. Unordered List (បញ្ជីចំណុច) -->
<ul>
  <li>មុខវិជ្ជា HTML</li>
  <li>មុខវិជ្ជា CSS</li>
</ul>

5. Explanation (ការពន្យល់កូដ):

  • <ol> បង្កើតលេខរៀង 1, 2 ស្វ័យប្រវត្តិដោយមិនបាច់វាយលេខដោយដៃឡើយ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/lists.html
  1. ជំហានទី ១៖ រៀបចំកូដ HTML5
  2. ជំហានទី ២៖ តុបតែងជាមួយ CSS3
  • មុខវិជ្ជា HTML
  • មុខវិជ្ជា CSS
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ <ol> សម្រាប់លំដាប់លំដោយលេខ និងប្រើ <ul> សម្រាប់ចំណុចធម្មតា ដោយមាន <li> ជាកូនផ្ទុកទិន្នន័យ។

07. HTML Tables

1. Definition (តើវាជាអ្វី?):

HTML Table ប្រើសម្រាប់រៀបចំទិន្នន័យជាក្រឡាតារាងមានជួរឈរ និងជួរដេកត្រឹមត្រូវតាមលំដាប់លំដោយ។

2. មុខងារសំខាន់ៗ៖

  • <table> (មេធំនៃតារាង)៖ រុំព័ទ្ធរចនាសម្ព័ន្ធតារាងទាំងមូល។
  • <tr> (មេជួរដេក - Table Row)៖ បង្កើតជួរដេកនីមួយៗ បើគ្មាន <tr> ទេ មិនអាចដាក់ក្រឡាបានឡើយ។
  • <th> (ក្រឡាក្បាលតារាង)៖ អក្សរដិតចំកណ្តាលសម្រាប់ចំណងជើងជួរនីមួយៗ។
  • <td> (ក្រឡាទិន្នន័យ)៖ ផ្ទុកទិន្នន័យធម្មតា។
  • colspan & rowspan (មេបញ្ចូលក្រឡា)៖ សម្រាប់បញ្ចូលក្រឡាច្រើនជាក្រឡាតែមួយតាមជួរឈរ ឬដេក។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់តារាងពិន្ទុសិស្ស តារាងតម្លៃ និងកាលវិភាគសិក្សា (ហាមប្រើសម្រាប់រៀបប្លង់ទំព័រ)។

4. Syntax (ទម្រង់កូដ):

<table border="1" style="width:100%; border-collapse:collapse;">
  <thead>
    <tr><th>វគ្គសិក្សា</th><th>តម្លៃ</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML & CSS</td><td>$45</td></tr>
  </tbody>
</table>

5. Explanation (ការពន្យល់កូដ):

  • border-collapse: collapse បញ្ចូលបន្ទាត់ស៊ុមពីរជាន់ឱ្យនៅសល់បន្ទាត់ទោលស្អាត។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/table.html
វគ្គសិក្សា តម្លៃ
HTML & CSS $45
7. Summary (សង្ខេបមេរៀន)៖ តារាងមាន <table> ជាមេ រៀបជួរដេកដោយ <tr> និងចែកក្រឡាដោយ <th> (ក្បាល) និង <td> (ទិន្នន័យ)។

HTML & CSS 08. HTML Forms

08. HTML Forms

1. Definition (តើវាជាអ្វី?):

HTML Form គឺជាប្រព័ន្ធប្រមូល និងបញ្ជូនទិន្នន័យពីអ្នកប្រើប្រាស់នៅលើ Browser ទៅកាន់ម៉ាស៊ីន Server។

2. មុខងារសំខាន់ៗ៖

  • <form> (មេធំនៃ Form)៖ កំណត់ផ្លូវបញ្ជូន (action) និងវិធីសាស្ត្រ (method="POST")។
  • <input> (ប្រអប់បញ្ចូល)៖ កំណត់ប្រភេទបញ្ចូលដូចជា text, email, password។
  • name (មេសម្គាល់ទិន្នន័យ - ខ្វះមិនបាន)៖ បើ Input គ្មាន Attribute name ទេ ទិន្នន័យក្នុងប្រអប់នោះនឹងមិនត្រូវបានផ្ញើទៅ Server ឡើយ។
  • <label> (ស្លាកឈ្មោះ)៖ ប្រើ for ភ្ជាប់ជាមួយ id របស់ Input ជួយឱ្យចុចចំអក្សរក៏លោតចូល Input។
  • required (មេបង្ខំ)៖ ទប់ស្កាត់កុំឱ្យចុច Submit បានបើទុកប្រអប់ទំនេរ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ទម្រង់ Login, ចុះឈ្មោះសិស្ស និងទម្រង់ផ្ញើសារទាក់ទង។

4. Syntax (ទម្រង់កូដ):

<form action="/submit" method="post">
  <label for="user-email">អ៊ីមែល៖</label>
  <input type="email" id="user-email" name="email" required>
  <button type="submit">ចុះឈ្មោះ</button>
</form>

5. Explanation (ការពន្យល់កូដ):

  • type="email" ពិនិត្យទម្រង់អ៊ីមែលស្វ័យប្រវត្តិ (ត្រូវតែមានសញ្ញា @)។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/form.html
អ៊ីមែល៖
7. Summary (សង្ខេបមេរៀន)៖ Form ត្រូវតែមាន <form> ជាមេ និងមាន name លើគ្រប់ Input ដើម្បីបញ្ជូនទិន្នន័យទៅ Server បានជោគជ័យ។

HTML & CSS 09. Semantic HTML5

09. Semantic HTML5 Elements

1. Definition (តើវាជាអ្វី?):

Semantic HTML5 គឺជាការប្រើប្រាស់ស្លាកកូដដែលមានអត្ថន័យច្បាស់លាស់បញ្ជាក់ពីតួនាទីមាតិកា ជំនួសឱ្យការប្រើ <div> គ្រប់កន្លែង។

2. មុខងារសំខាន់ៗ៖

  • <header> (មេផ្នែកក្បាល)៖ ផ្ទុក Logo, ចំណងជើង ឬរបារស្វែងរក។
  • <nav> (មេម៉ឺនុយ)៖ ផ្ទុកតំណភ្ជាប់ Navigation។
  • <main> (មេខ្លឹមសារចម្បង - តែមួយគត់)៖ ផ្ទុកមាតិកាសំខាន់បំផុតនៃទំព័រ (ក្នុង ១ ទំព័រត្រូវមានតែមួយគត់)។
  • <article> & <section> (មេបំណែកមាតិកា)៖ <article> សម្រាប់មាតិកាឯករាជ្យ (ដូចជា Blog) រីឯ <section> សម្រាប់បែងចែកផ្នែក។
  • <footer> (មេជើងទំព័រ)៖ ផ្ទុកព័ត៌មានរក្សាសិទ្ធិ និងតំណភ្ជាប់បន្ថែម។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរៀបចំគ្រោងឆ្អឹងទំព័រធំៗ ដើម្បីគាំទ្រ SEO និង Screen Reader។

4. Syntax (ទម្រង់កូដ):

HTML & CSS 11. Introduction to CSS3

11. Introduction to CSS3

1. Definition (តើវាជាអ្វី?):

CSS3 (Cascading Style Sheets) គឺជាភាសាសម្រាប់តុបតែងពណ៌ ពុម្ពអក្សរ គម្លាត និងរៀបចំប្លង់ឱ្យធាតុ HTML មានភាពទាក់ទាញ។

2. មុខងារសំខាន់ៗ៖

  • Selector (តួចាប់ធាតុ)៖ បើគ្មាន Selector ទេ Browser មិនដឹងថាត្រូវយកកូដរចនាទៅដាក់លើ Element ណាមួយឡើយ។
  • Property (លក្ខណៈត្រូវរចនា)៖ ដូចជា color, background, padding។
  • Value (តម្លៃកំណត់)៖ តម្លៃដែលត្រូវផ្តល់ឱ្យ Property (ឧ. red, 16px)។
  • External Link (មេភ្ជាប់ឯកសារ)៖ ប្រើ <link rel="stylesheet" href="style.css"> ក្នុង <head> ដើម្បីឱ្យទំព័រ HTML ស្គាល់ CSS។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ External CSS សម្រាប់រចនាគេហទំព័រទាំងមូល។

4. Syntax (ទម្រង់កូដ):

.card {
  background-color: #E0F2FE;
  color: #0284C7;
  padding: 12px;
  border-radius: 6px;
}

5. Explanation (ការពន្យល់កូដ):

  • .card ចាប់យកគ្រប់ Element ដែលមាន class="card" មកដាក់ Style ព្រមគ្នា។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/css-intro.html
ប្រអប់អត្ថបទតុបតែងដោយ External CSS (.card)
7. Summary (សង្ខេបមេរៀន)៖ CSS ដំណើរការតាមក្បួន Selector { Property: Value; } ហើយត្រូវភ្ជាប់ជាមួយ HTML តាមរយៈស្លាក <link>។

12. CSS Selectors & Pseudo-Classes

1. Definition (តើវាជាអ្វី?):

CSS Selectors គឺជាគន្លឹះសម្រាប់ចង្អុលបង្ហាញ និងចាប់យកធាតុ HTML មកដាក់ស្ទីលតុបតែងតាមបំណង។

2. មុខងារសំខាន់ៗ៖

  • .class (មេពេញនិយមបំផុត)៖ ប្រើសញ្ញាចុច (.) ចាប់យកធាតុតាមឈ្មោះ Class អាចប្រើឡើងវិញបានច្រើនកន្លែង។
  • #id (មេសម្គាល់ទោល)៖ ប្រើសញ្ញាទ្រុងជ្រូក (#) សម្រាប់ធាតុតែមួយគត់ក្នុងទំព័រ។
  • :hover (មេអន្តរកម្ម Mouse)៖ ដំណើរការកូដ Style លុះត្រាតែអ្នកប្រើប្រាស់ដាក់ Mouse ពីលើធាតុនោះ។
  • :focus (មេអន្តរកម្មចុច)៖ ដំណើរការពេល Cursor កំពុងស្ថិតក្នុងប្រអប់ Input។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់ Class ជាទូទៅ និងប្រើ Pseudo-classes លើប៊ូតុង ឬតំណភ្ជាប់។

4. Syntax (ទម្រង់កូដ):

.btn {
  background: #0284C7;
  color: #FFFFFF;
  padding: 6px 14px;
  border-radius: 4px;
}
.btn:hover {
  background: #0369A1; /* ប្តូរពណ៌ពេល Hover */
}

5. Explanation (ការពន្យល់កូដ):

  • .btn:hover ជួយឱ្យប៊ូតុងមានចលនាឆ្លើយតបពេលអ្នកប្រើដាក់ Mouse លើវា។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/selectors.html
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ Class Selector (.) ជាចម្បងក្នុងគម្រោង និងប្រើ Pseudo-class (:hover) បង្កើតភាពរស់រវើកដល់ប៊ូតុង។

13. CSS Colors, Backgrounds & Gradients

1. Definition (តើវាជាអ្វី?):

2. មុខងារសំខាន់ៗ៖

  • color (ពណ៌អក្សរ)៖ កំណត់ពណ៌លើអត្ថបទ។
  • background-color (ពណ៌ផ្ទៃក្រោយ)៖ កំណត់ពណ៌ផ្ទៃប្រអប់ (ប្រើ HEX, RGBA សម្រាប់ពណ៌ថ្លា)។
  • linear-gradient() (មេច្របល់ពណ៌)៖ បង្កើតផ្ទៃច្របល់ពណ៌ទំនើបដោយមិនចាំបាច់ប្រើរូបភាពធ្ងន់ៗ។
  • background-size: cover; (មេទាញរូបភាព)៖ ពង្រីករូបភាពឱ្យពេញប្រអប់ស្អាតដោយមិនខូចសមាមាត្រ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រចនាផ្ទៃ Hero Banner, កាតផលិតផល និងប៊ូតុង។

4. Syntax (ទម្រង់កូដ):

.banner {
  background: linear-gradient(135deg, #0284C7 0%, #0F172A 100%);
  color: #FFFFFF;
  padding: 18px;
  border-radius: 6px;
}

5. Explanation (ការពន្យល់កូដ):

  • 135deg បញ្ជាឱ្យពណ៌រត់បញ្ឆិតពីខៀវទៅទឹកប៊ិចចាស់។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/gradient.html
🎨 CSS3 Linear Gradient Background (135deg)
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ color សម្រាប់អក្សរ និងប្រើ linear-gradient() បង្កើតផ្ទៃខាងក្រោយទំនើបទាក់ទាញភ្នែក។

  • padding (គម្លាតក្នុង)៖ រុញមាតិកាចេញពីស៊ុមខាងក្នុង (មិនប៉ះពាល់ផ្ទៃខាងក្រៅឡើយ)។
  • border (ស៊ុមព័ទ្ធជុំវិញ)៖ បន្ទាត់ខណ្ឌចែករវាងខាងក្នុង និងខាងក្រៅ។
  • margin (គម្លាតក្រៅ)៖ រុញប្រអប់ឱ្យឃ្លាតចេញពីប្រអប់ដទៃទៀត។
  • box-sizing: border-box; (មេសង្គ្រោះប្លង់ - ខ្វះមិនបាន)៖ បញ្ចូល Padding និង Border ក្នុងទទឹង Width តែមួយ បើមិនដាក់ទេ ប្រអប់នឹងរីកធំខូចប្លង់។

3. When to Use (តើប្រើនៅពេលណា?):

ត្រូវកំណត់ * { box-sizing: border-box; } នៅដើមឯកសារ CSS គ្រប់គម្រោង។

4. Syntax (ទម្រង់កូដ):

.card {
  box-sizing: border-box; /* ការពារកុំឱ្យរីកទំហំលើស */
  width: 260px;

  border-radius: 8px;

  • ទោះបីជាបន្ថែម Padding 16px ក៏ប្រអប់នៅតែមានទទឹង 260px គត់ដដែល។

https://localhost:5500/box-model.html

Content + Padding + Border

16. CSS Display and Position

1. Definition (តើវាជាអ្វី?):

display កំណត់របៀបដែលធាតុបង្ហាញខ្លួន រីឯ position កំណត់កូអរដោនេទីតាំងនៃធាតុលើអេក្រង់។

2. មុខងារសំខាន់ៗ៖

  • position: relative; (មេកំណត់ព្រំដែន)៖ ត្រូវដាក់លើប្រអប់មេ បើមិនដាក់ទេ កូនដែលមាន absolute នឹងរត់ពេញអេក្រង់ Browser។
  • position: absolute; (កូនហោះតាមចិត្ត)៖ កំណត់ទីតាំងជាក់លាក់តាម top, right ធៀបនឹងប្រអប់មេ relative។
  • position: sticky; (មេស្អិតជាប់)៖ ដើរតួធម្មតា តែដល់ពេល Scroll ប៉ះ top: 0 វានឹងនៅស្អិតជាប់ផ្នែកខាងលើរហូត។
  • position: fixed; (មេជាប់នឹងអេក្រង់)៖ ជាប់នឹងកញ្ចក់អេក្រង់រហូត ទោះបី Scroll ទៅណាក៏ដោយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ Sticky Header, ប៊ូតុងឆាតអណ្តែតលើអេក្រង់ និងស្លាក Badge លើកាត។

4. Syntax (ទម្រង់កូដ):

  top: 8px;
  right: 8px;
}

5. Explanation (ការពន្យល់កូដ):

  • .badge នឹងស្ថិតនៅជ្រុងលើស្តាំនៃ .card ជានិច្ច មិនរត់ចេញក្រៅឡើយ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/position.html
HOT Product Card
Positioned Badge

HTML & CSS 17. CSS Flexbox

17. CSS Flexbox Layout

1. Definition (តើវាជាអ្វី?):

CSS Flexbox គឺជាប្រព័ន្ធរៀបចំប្លង់ ១ វិមាត្រ (1D Layout) សម្រាប់រៀបចំ តម្រឹម និងចែកចាយគម្លាតធាតុកូនតាមជួរដេក ឬជួរឈរយ៉ាងបត់បែន។

2. មុខងារសំខាន់ៗ៖

  • display: flex; (ជាមេនៃ Flexbox - ខ្វះមិនបាន)៖ ត្រូវដាក់លើប្រអប់មេជាដាច់ខាត បើគ្មានវាទេ Properties ខាងក្រោមទាំងអស់នឹងមិនដំណើរការឡើយ។
  • flex-direction (មេកំណត់ទិស)៖ កំណត់ឱ្យរត់ជាជួរដេក (row) ឬជួរឈរ (column)។
  • justify-content (មេតម្រឹមអ័ក្សដេក)៖ រុញធាតុទៅកណ្តាល ឬរុញដាច់ពីគ្នាសងខាង (space-between)។
  • align-items (មេតម្រឹមអ័ក្សឈរ)៖ តម្រឹមធាតុឱ្យនៅចំកណ្តាលកម្ពស់ស្មើគ្នា (center)។
  • gap (មេគម្លាត)៖ កំណត់គម្លាតស្មើៗគ្នារវាងធាតុកូននីមួយៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់របារ Navbar, ការដាក់ធាតុឱ្យចំកណ្តាលអេក្រង់ និងការរៀបប៊ូតុងមួយជួរ។

4. Syntax (ទម្រង់កូដ):

.navbar {
  display: flex; /* បើកដំណើរការ Flexbox ជាមេ */
  justify-content: space-between; /* រុញ Logo ទៅឆ្វេង Menu ទៅស្តាំ */
  align-items: center; /* កណ្តាលជួរឈរស្មើគ្នា */
  padding: 10px 16px;
}

5. Explanation (ការពន្យល់កូដ):

  • display: flex បញ្ជាឱ្យធាតុកូនរត់ជាជួរដេកភ្លាមៗដោយស្វ័យប្រវត្តិ។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/flexbox.html
LOGO BRAND
HomeAboutContact
7. Summary (សង្ខេបមេរៀន)៖ ត្រូវដាក់ display: flex; ជាមេជាមុនសិន ទើបអាចប្រើ justify-content សម្រាប់អ័ក្សដេក និង align-items សម្រាប់អ័ក្សឈរបាន។

HTML & CSS 18. CSS Grid

18. CSS Grid Layout

1. Definition (តើវាជាអ្វី?):

CSS Grid គឺជាប្រព័ន្ធរៀបចំប្លង់ ២ វិមាត្រ (2D Layout) ដែលអនុញ្ញាតឱ្យគ្រប់គ្រងទាំងជួរឈរ (Columns) និងជួរដេក (Rows) ក្នុងពេលតែមួយ។

2. មុខងារសំខាន់ៗ៖

  • display: grid; (ជាមេនៃ Grid System - ខ្វះមិនបាន)៖ ត្រូវដាក់លើប្រអប់មេ បើគ្មានវាទេ រាល់ Properties ផ្សេងទៀតរបស់ Grid នឹងមិនដំណើរការឡើយ។
  • grid-template-columns (មេកំណត់ជួរឈរ)៖ កំណត់ចំនួន និងប្រវែងទទឹងនៃជួរឈរ (ឧ. repeat(3, 1fr))។
  • grid-template-rows (មេកំណត់ជួរដេក)៖ កំណត់កម្ពស់នៃជួរដេកនីមួយៗ។
  • gap (មេគម្លាតក្រឡា)៖ កំណត់គម្លាតរវាងក្រឡានីមួយៗដោយមិនបាច់ប្រើ Margin។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បញ្ជីកាតផលិតផល, Gallery រូបភាព និងគ្រោងឆ្អឹង Dashboard ធំៗ។

4. Syntax (ទម្រង់កូដ):

.grid-container {
  display: grid; /* បើកដំណើរការ Grid System (ខ្វះមិនបាន) */
  grid-template-columns: repeat(3, 1fr); /* ចែក ៣ ជួរឈរស្មើគ្នា */
  gap: 12px; /* គម្លាតរវាងក្រឡា ១២px */
}

5. Explanation (ការពន្យល់កូដ):

  • repeat(3, 1fr) ប្រើ Fractional unit (fr) ចែកទំហំទំនេរជា ៣ ស្មើៗគ្នា។

https://localhost:5500/grid.html

HTML & CSS 19. Responsive Web Design

19. Responsive Web Design & Media Queries

1. Definition (តើវាជាអ្វី?):

Responsive Web Design គឺជាវិធីសាស្ត្ររៀបចំគេហទំព័រឱ្យបត់បែនទំហំ និងប្លង់ដោយស្វ័យប្រវត្តិតាមរយៈ @media queries ដើម្បីឱ្យមើលឃើញស្អាតលើគ្រប់ឧបករណ៍ (ទូរស័ព្ទ, Tablet, និងកុំព្យូទ័រ)។

2. មុខងារសំខាន់ៗ៖

  • @media (មេកំណត់លក្ខខណ្ឌ - ខ្វះមិនបាន)៖ បញ្ជាឱ្យ Browser ដំណើរការកូដ CSS តែនៅពេលអេក្រង់ធ្លាក់ក្នុងលក្ខខណ្ឌកំណត់។
  • min-width (មេ Mobile-First)៖ ដំណើរការនៅពេលអេក្រង់មានទំហំ ចាប់ពីប៉ុណ្ណឹងឡើងទៅ (ឧ. min-width: 768px គឺចាប់ពី Tablet ឡើងទៅកុំព្យូទ័រ)។
  • max-width (មេ Desktop-First)៖ ដំណើរការនៅពេលអេក្រង់មានទំហំ ត្រឹមប៉ុណ្ណឹងចុះក្រោម (ឧ. max-width: 768px គឺសម្រាប់តែអេក្រង់ Tablet និងទូរស័ព្ទដៃប៉ុណ្ណោះ)។
  • <meta name="viewport"> (មេបើកផ្លូវលើទូរស័ព្ទ)៖ ត្រូវតែមានក្នុង <head> បើគ្មានវាទេ Browser លើទូរស័ព្ទនឹងមិនស្គាល់ Media Query ឡើយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ max-width: 768px នៅពេលយើងសរសេរប្លង់កុំព្យូទ័ររួចរាល់ ហើយចង់កែសម្រួល ឬបង្រួមប្លង់នោះឱ្យសមស្របពេលមើលលើទូរស័ព្ទដៃ។

4. Syntax (ទម្រង់កូដប្រើប្រាស់ max-width):

/* ១. ប្លង់លំនាំដើមសម្រាប់កុំព្យូទ័រ (Desktop: បង្ហាញ ៣ ជួរឈរ) */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* ២. អេក្រង់ត្រឹម ៧៦៨px ចុះក្រោម (Tablet & Mobile: បង្រួមមកសល់ ១ ជួរឈរ) */
@media screen and (max-width: 768px) {
  .container {
    grid-template-columns: 1fr; /* ប្តូរមកជួរឈរទោលលើទូរស័ព្ទ */
  }
}

5. Explanation (ការពន្យល់កូដ):

  • max-width: 768px មានន័យថាឱ្យតែកញ្ចក់អេក្រង់មានទំហំស្មើ ឬតូចជាង 768px នោះ .container នឹងប្តូរមកជាជួរឈរទោល (1fr) ភ្លាមៗ។

Responsive Preview (max-width: 768px)

7. Summary (សង្ខេបមេរៀន)៖ ត្រូវចាំថា min-width ដំណើរការពីទំហំកំណត់ ឡើងទៅលើ (Mobile-First) រីឯ max-width ដំណើរការពីទំហំកំណត់ ចុះមកក្រោម (Desktop-First) សម្រាប់កែសម្រួលប្លង់លើទូរស័ព្ទដៃ។

HTML & CSS 20. CSS Units & Math Functions

20. CSS Units & Math Functions

1. Definition (តើវាជាអ្វី?):

CSS Units កំណត់ខ្នាតរង្វាស់ទំហំ រួមមានខ្នាតថេរ (px), ខ្នាតធៀប (rem, vw, vh) និងអនុគមន៍គណនាទំនើប។

2. មុខងារសំខាន់ៗ៖

  • rem (មេទំហំអក្សរស្តង់ដារ)៖ ធៀបនឹង Root HTML (1rem = 16px) ល្អបំផុតសម្រាប់ Accessibility។
  • vw & vh (មេទំហំកញ្ចក់អេក្រង់)៖ 100vw = ពេញទទឹងអេក្រង់, 100vh = ពេញកម្ពស់អេក្រង់។
  • clamp(min, preferred, max) (មេបង្រួមពង្រីកស្វ័យប្រវត្តិ)៖ កំណត់ទំហំអក្សរឱ្យប្រែប្រួលរវាងតម្លៃតូចបំផុត និងធំបំផុតតាមអេក្រង់។
  • calc() (មេគណនាលេខ)៖ គណនាច្របល់ខ្នាតចូលគ្នា (ឧ. calc(100vh - 70px))។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ rem សម្រាប់ Typography និង clamp() សម្រាប់ចំណងជើងធំៗ។

4. Syntax (ទម្រង់កូដ):

.hero-title {
  font-size: clamp(1.2rem, 2.5vw + 0.5rem, 2rem);
}
.container {
  width: min(100% - 2rem, 1140px);
}

5. Explanation (ការពន្យល់កូដ):

  • ទំហំអក្សររីកធំលើកុំព្យូទ័រ និងរួមតូចលើទូរស័ព្ទដោយស្វ័យប្រវត្តិតាម clamp()។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/fluid.html
Fluid Heading with clamp() • រីករួមតាមអេក្រង់ស្វ័យប្រវត្តិ
7. Summary (សង្ខេបមេរៀន)៖ ប្រើ rem សម្រាប់ទំហំអក្សរ និងប្រើ clamp() បង្កើត Fluid Typography ដោយមិនបាច់សរសេរ Media Query ច្រើនដង។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 23
HTML & CSS 21. CSS Transitions and Transforms

21. CSS Transitions and Transforms

1. Definition (តើវាជាអ្វី?):

transition បង្កើតចលនាផ្លាស់ប្តូរទន់ភ្លន់ រីឯ transform ប្រើសម្រាប់រំកិល ពង្រីក ឬបង្វិលរូបរាង Element។

2. មុខងារសំខាន់ៗ៖

  • transition (មេពន្យឺតចលនា)៖ បើគ្មានវាទេ ការប្តូរពណ៌ ឬទីតាំងនឹងកន្ត្រាក់ភ្លាមៗ គ្មានចលនារលូនឡើយ។
  • transform: translateY(-5px); (មេរំកិល)៖ លើកប្រអប់ឡើងលើបន្តិចពេល Hover។
  • transform: scale(1.05); (មេពង្រីក)៖ ពង្រីកប្រអប់ឱ្យធំបន្តិច។
  • transform: rotate(45deg); (មេបង្វិល)៖ បង្វិលមុំធាតុ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើតចលនាពេល Hover លើប៊ូតុង និងកាតផលិតផល។

4. Syntax (ទម្រង់កូដ):

.card {
  transition: transform 0.3s ease; /* រយៈពេល ០.៣ វិនាទី */
}
.card:hover {
  transform: translateY(-5px); /* អណ្តែតឡើងលើ ៥px */
}

5. Explanation (ការពន្យល់កូដ):

  • transform ដំណើរការលើ GPU ធ្វើឱ្យចលនារលូនខ្លាំង មិនទាក់អេក្រង់។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/hover.html
ដាក់ Mouse លើប៊ូតុង (Hover Animation)
7. Summary (សង្ខេបមេរៀន)៖ ត្រូវដាក់ transition លើ Element មេជាមុន ទើបពេល Hover ជាមួយ transform ចេញមកមានចលនារលូន។

HTML & CSS 22. CSS Animations (@keyframes)

22. CSS Animations (@keyframes)

1. Definition (តើវាជាអ្វី?):

CSS Animations គឺជាការបង្កើតចលនាស្វ័យប្រវត្តិច្រើនដំណាក់កាលដោយមិនបាច់រង់ចាំការដាក់ Mouse ពីលើឡើយ។

2. មុខងារសំខាន់ៗ៖

  • @keyframes (មេបង្កើតដំណាក់កាលចលនា)៖ កំណត់ដំណើរដើមទងពី 0% ដល់ 100%។
  • animation-name (ឈ្មោះចលនា)៖ ហៅឈ្មោះ @keyframes មកប្រើ។
  • animation-duration (រយៈពេលចលនា)៖ កំណត់ថាចលនាត្រូវរត់ប៉ុន្មានវិនាទី។
  • infinite (មេវិលជុំមិនឈប់)៖ បញ្ជាឱ្យចលនាដំណើរការជារៀងរហូត។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ Loading Spinners, ភ្លើងលោត Pulse និង Effect បង្ហាញទំព័រដំបូង។

4. Syntax (ទម្រង់កូដ):

@keyframes spin {
  100% { transform: rotate(360deg); }
}
.spinner {
  width: 28px; height: 28px;
  border: 3px solid #E0F2FE;
  border-top-color: #0284C7;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}

5. Explanation (ការពន្យល់កូដ):

  • រង្វង់វិល 360 ដឺក្រេក្នុងល្បឿនថេរ 1 វិនាទីជារៀងរហូតតាមរយៈ infinite។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/spinner.html
កំពុងដំណើរការ (Loading...)
7. Summary (សង្ខេបមេរៀន)៖ បង្កើតចលនាដោយប្រកាស @keyframes រួចហៅប្រើក្នុង Element តាមរយៈ Property animation។

HTML & CSS 23. Advanced CSS (Variables, :is, :has)

23. Advanced CSS (Variables, :is, :has)

1. Definition (តើវាជាអ្វី?):

មុខងារ CSS កម្រិតខ្ពស់រួមមាន CSS Variables (Custom Properties) និង Selectors ជំនាន់ថ្មីជួយឱ្យកូដខ្លី និងឆ្លាតវៃ។

2. មុខងារសំខាន់ៗ៖

  • :root (មេផ្ទុកអថេរសកល)៖ កន្លែងប្រកាស CSS Variables ដើម្បីហៅប្រើបានគ្រប់កន្លែង។
  • var(--name) (មេទាញតម្លៃអថេរ)៖ ហៅពណ៌ ឬទំហំមកប្រើ បើចង់ប្តូរ Theme ដូរតែក្នុង :root មួយកន្លែងគឺរួចរាល់។
  • :has() (មេចាប់ប្រអប់មេ - Parent Selector)៖ ចាប់ស្ទីលលើប្រអប់មេដោយផ្អែកលើវត្តមានរបស់កូនខាងក្នុង។
  • :is() (មេបង្រួម Selector)៖ សរសេរកាត់បន្ថយការសរសេរ Selector វែងៗផ្ទួនគ្នា។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើត Dark/Light Mode និងគ្រប់គ្រងប្រព័ន្ធពណ៌ Design System។

4. Syntax (ទម្រង់កូដ):

:root {
  --primary-color: #0284C7; /* ប្រកាសអថេរពណ៌មេ */
}
.card {
  border: 2px solid var(--primary-color);
  padding: 10px;
}

5. Explanation (ការពន្យល់កូដ):

  • var(--primary-color) ហៅតម្លៃពណ៌ដែលបានប្រកាសក្នុង :root មកប្រើប្រាស់។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/variables.html
Card Styled with CSS Variable (var(--primary-color))
7. Summary (សង្ខេបមេរៀន)៖ CSS Variables ប្រកាសក្នុង :root ជួយឱ្យការកែប្រែពណ៌ប្រព័ន្ធទាំងមូលរហ័សទាន់ចិត្ត និងងាយស្រួលធ្វើ Dark Mode។

HTML & CSS 24. CSS Architecture and Best Practices

24. CSS Architecture & BEM Methodology

1. Definition (តើវាជាអ្វី?):

BEM (Block__Element--Modifier) គឺជាស្តង់ដារអន្តរជាតិនៃការដាក់ឈ្មោះ Class ក្នុង CSS ដើម្បីកុំឱ្យជាន់ឈ្មោះគ្នា និងងាយស្រួលធ្វើការងារជាក្រុម។

2. មុខងារសំខាន់ៗ៖

  • Block (.card) [តួមេឯករាជ្យ]៖ ប្រអប់មេធំដែលតំណាងឱ្យ Component មួយទាំងមូល។
  • Element (.card__title) [តួកូនក្នុងមេ]៖ ធាតុកូនក្នុង Block ភ្ជាប់ដោយសញ្ញា Underscore ពីរ (__)។
  • Modifier (.card--featured) [តួប្តូរទម្រង់]៖ កំណែពិសេសប្តូរពណ៌ ឬទំហំ ភ្ជាប់ដោយសញ្ញាដកពីរ (--)។

3. When to Use (តើប្រើនៅពេលណា?):

អនុវត្តក្នុងគម្រោងធំៗដើម្បីជៀសវាងការប្រើប្រាស់ !important។

4. Syntax (ទម្រង់កូដ):

<article class="card card--featured">
  <h3 class="card__title">HTML & CSS Pro</h3>
  <button class="card__btn">ចុះឈ្មោះ</button>
</article>

5. Explanation (ការពន្យល់កូដ):

  • គ្រប់ Class មាន Specificity ស្មើគ្នា ងាយស្រួលគ្រប់គ្រង និងកែប្រែបំផុត។

6. Output (លទ្ធផលនៅលើ Browser):

https://localhost:5500/bem.html
HTML & CSS Pro
7. Summary (សង្ខេបមេរៀន)៖ ក្បួន BEM (Block, Element, Modifier) ជួយឱ្យកូដ CSS មានរបៀបរៀបរយខ្ពស់ មិនជាន់ឈ្មោះគ្នា និងងាយពង្រីកគម្រោងទៅមុខ។
